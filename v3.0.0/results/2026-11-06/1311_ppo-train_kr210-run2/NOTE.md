# 참고 — 이 모델은 PPO 10회까지만 학습했다 (2026-11-06 사용자 결정)

- **학습량**
  - 모방 학습 3회와 PPO 강화학습 **10회**만 했다(약 27분).
  - 처음에는 40회로 시작했지만, 사용자 요청("40회 하지 말고 일단 10회만, 결과 보고 결정")에 따라 10회로 다시 시작했다.
  - 결과를 본 뒤 사용자가 "학습은 여기까지"로 정해 **추가 학습은 하지 않았다**.
- **채택 모델:** `policy-best.json` = **5회째**
  - 연습장 시험 결과: 모방 직후 61.9% → 5회째 71.3% → 10회째 62.3%. 5회째가 가장 좋았다.
  - 10회째 모델은 `policy-last.json`, 중간 모델은 `checkpoints/iter-000·005·010.json`에 있다.
- **실제 셀 10분 결과**(평가 시드 11·12·13)
  - PPO 71.5%
  - 규칙 경로(번갈아) 72.9%
  - 진화 탐색 84.0%
  - 1차 PPO 65.6%
- **학습량이 적다는 점:** 1차 PPO는 40회를 학습했다. 이 모델은 10회만 학습했으므로 학습을 더 하거나 시범을 늘리면 달라질 수 있다.
- **이어서 학습하려면:**
  ```bash
  node tools/ppo-train.mjs --resume results/2026-11-06/1311_ppo-train_kr210-run2/policy-last.json --name run2b
  ```
  또는 시범을 늘린 뒤 `tools/pipeline.mjs`로 학습한다.
