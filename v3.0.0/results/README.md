## 폴더 이름 = `<날짜>/<시각>_<종류>_<이름>`
- **시각**: 이 PC 시각(한국), 실행을 시작한 시각이다. 같은 분에 같은 이름이 있으면 `-2`, `-3`을 붙인다.
- **종류**와 만드는 명령은 아래와 같다.

| 종류 | 단계 | 명령 |
|---|---|---|
| `baseline` | 0단계: 규칙 경로만 | `node tools/baseline.mjs` |
| `cem` | 1단계: 진화 탐색 | `node tools/train.mjs` |
| `ppo-train` | 2단계: PPO 학습 | `node tools/ppo-train.mjs` |
| `ppo-eval` | 학습된 정책을 전체 셀 10분 과제로 평가 | `node tools/ppo-eval.mjs` |
| `episode` | 단발 헤드리스 실행 | `node tools/episode.mjs` |
| `cem-demos` | 진화 탐색 시범 수집(PPO 모방 교사) | `node tools/cem-demos.mjs` |
| `pipeline` | 시범 → PPO → 평가 → 비교 보고서 한 번에 | `node tools/pipeline.mjs` (또는 `train.bat`) |

- **이름**: `<로봇>-<구성>-s<시드>` 등 조건 요약이다.
- 모든 실행 폴더에는 `run.json`이 있다. 내용은 실행한 명령, 시작·끝 시각, git 커밋, Node 버전, 요약이다. 2026-11-06에 정리한 이전 실행에는 없다.

| 이름 | 측면 로봇 | 회수하는 로봇 |

## 쓸기 방향 (`--lane-dir`, 대형 규칙 경로)
| 값 | 뜻 |
|---|---|
| `robot` | 스나우트 쪽에서 로봇 쪽으로 쓴다. 열린 면이 로봇을 본다(v1.1.2 기본) |
| `snout` | 로봇 쪽에서 스나우트 쪽으로 쓴다. 열린 면이 스나우트를 본다. 담은 채 물러나 천천히 돌린 뒤 박스로 옮긴다 |
| `alternate` | 사이클마다 번갈아 쓴다 |

## 파일
- **3D 재생 파일**: 이름은 `<방법>-<구성>-s<시드>.rsim.json.gz`이고, 방법은 `rule` · `cem` · `ppo` 중 하나다. 앱 '에피소드 재생'에서 연다. 모두 git에 올린다(2026-11-06부터, 다른 PC에서도 바로 3D로 본다). 같은 명령으로 다시 만들어도 같다(시드 고정, 결정적 실행).
- **cem 폴더**: `report.md`, `log.json`(모든 시도)
- **ppo-train 폴더**

| 파일 | 내용 |
|---|---|
| `policy-best.json` | **최종 채택 정책.** 앱 [정책 불러오기 (PPO)]로 쓰는 파일 |
| `policy-last.json` | 마지막 반복의 정책 |
| `checkpoints/iter-NNN.json` | 5회마다 저장한 중간 정책. `1814_ppo-train_kr210-run1`에는 없다 |
| `train-curve.json` · `train-report.md` | 학습 기록 |
| `cell-eval-alone.md` | 학습 직후 전체 셀 평가 |

- **ppo-eval 폴더**: `cell-eval-<구성>.md`, 3D 재생 파일

> "40번 학습"은 신경망 하나를 40번 고쳐 쓴 것이다. 반복마다 파일이 생기지 않는다.
