- **정책:** `../0947_ppo-train_kr210-run3/policy-last.json` = 40회째. `checkpoints/iter-040.json`과 저장 시각·평가 기록만 다르고 모델 값은 같다.
  - 폴더 이름 `kr210-run3-alone`은 도구가 정책 폴더 이름으로 자동으로 붙였다. **best(30회째)가 아니라 last(40회째)** 평가다.
