# docs/ — 기술 문서 (날짜·시각별 기록)

**문서는 덮어쓰지 않는다.** 결과가 바뀔 때마다 새 폴더를 만든다(2026-11-06 사용자 결정).
- 폴더 이름: `<날짜>_<시각>_<제목>/`
- 폴더 안: `.docx`(문서), `images/`(그림), `build/`(그 문서를 만든 스크립트)
- 스크립트가 읽는 결과 경로는 `build/` 맨 위에 적혀 있어, 같은 문서를 다시 만들 수 있다.

| 날짜·시각 | 문서 | 다룬 결과 |
|---|---|---|
| 2026-11-06 08:45 | `2026-11-06_0845_AI학습_기술문서/` | 학습 구조 전체 첫 판(계층형 B, 진화 탐색, PPO 1차), 결과 파일 이름 — 11:15 개정판으로 대체(보존) |
| **2026-11-06 11:15** | **`2026-11-06_1115_AI학습_기술문서/`** | **최신 전체 문서(개정판)**: 세 방법(규칙 경로·진화 탐색·PPO)의 역할과 이유, [A] 결과, [B] 진행 상황(4/16), 기록·재현 구조 |

다시 만들기 (v3.0.0 폴더에서):
```bash
python docs/<폴더>/build/figures.py . docs/<폴더>/images        # 그림 (matplotlib)
python docs/<폴더>/build/make_docx.py . docs/<폴더>/images docs/<폴더>/<이름>.docx   # 문서 (python-docx)
```
