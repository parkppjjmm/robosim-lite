다시 만들기 (v3.0.0 폴더에서):
```bash
python docs/<폴더>/build/figures.py . docs/<폴더>/images        # 그림 (matplotlib)
python docs/<폴더>/build/make_docx.py . docs/<폴더>/images docs/<폴더>/<이름>.docx   # 문서 (python-docx)
```
4판부터 앱 화면 스크린샷(`images/s*.png`)은 `build/capture/`의 Node 스크립트로 찍는다(헤드리스 Chrome, 앱 서버 8300 필요): `shots.mjs`(앱), `term.mjs`(train.bat 콘솔).
