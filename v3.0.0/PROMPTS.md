## 공통 전제 (모든 단계)
- 규칙은 루트 `CLAUDE.md`, 진행 상황은 `HANDOFF.md`. 릴리스한 폴더(`v1.0.0`~`v1.1.2`)와 태그는 수정하지 않는다. 작업은 `v3.0.0/` 안에서만 한다.
- AI는 **J1~J6 전 관절**을 움직인다(하위 정책 Δq). 모든 Δq는 안전 필터를 거친다. 물리보다 안전 검사가 먼저다.
- **AI 로봇은 1대**(대형·왼쪽·오른쪽 중 선택)만 둔다. **나머지는 기존 v1.1.2 경로·조정기 규칙 그대로** 둔다.
- 목표 회수율(기본 80%)·제한 시간(기본 600 s)·기준 영역(스나우트 앞 작업 영역)·센서(상부 1~2대)는 **설정값**이다.
- 정책 관측은 **센서 격자**만 쓴다. 정답 입자 위치는 보상·평가에만 쓴다.
- 순수 계산 모듈은 DOM 비의존. 브라우저 의존성 추가 금지(Three·Rapier만). Node 도구는 표준 라이브러리만 쓴다. Python 패키지는 `train/.venv`에만 설치한다(전역 설치 금지).
- 기능을 바꾸면 `node tests/run-all.mjs`(필요하면 `--full`)를 다시 돌린다. 브라우저 확인은 `python serve.py 8300 --no-browser`로 하고, **끝나면 서버를 끈다.**
- Windows에서 한글이 든 패치는 파일로 작성해 실행한다.
