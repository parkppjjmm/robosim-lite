## 메모 — D-1 "앱 화면 반영"과 "혼자 하는 학습"의 차이
- **(a) 앱 화면 반영**
  - 오늘 만든 기능은 지금 명령어(헤드리스)로만 돌릴 수 있다: 측면 모드 3, 쓸기 방향, 2차 PPO 모델.
  - 이것을 브라우저 앱의 드로스 셀 패널·학습 패널에서 직접 고르고, 실시간 3D로 보게 하는 것이다.
  - 학습을 새로 하는 기능은 아니다.
- **(b) 혼자 하는 학습**
  - 사용자가 Claude 없이 직접 진화 탐색 시범 수집 → PPO 학습 → 평가 → 비교 보고서까지 돌리고 결과를 보는 기능이다.
  - 지금도 명령 한 줄(`node tools/pipeline.mjs …`)로 되지만, 명령어를 몰라도 되게 만든다.
  - 방법 1: 더블클릭 실행 파일(`학습.bat`처럼 질문에 답하면 실행)
  - 방법 2: 앱 학습 패널의 "PPO 학습 시작" 버튼(브라우저에서 몇 시간 돌리기는 불안정해 실행 파일을 추천)
