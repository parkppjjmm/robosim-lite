# RoboSim Lite v3.0.0

> 이 폴더는 **v3.0.0 개발 폴더**입니다(요구사항 `PRD_v.3.0.0.md`, 포트 8300). 뼈대는 v1.1.2(태그 `v1.1.2`)이고, 여기에 **AI 기반 드로스 제거**를 더합니다. AI가 **J1~J6 전 관절**을 학습해(계층형: 상위 = 구역·스킬 선택, 하위 = 관절 Δq 20 Hz), 스나우트 앞 작업 영역 드로스를 **제한 시간(기본 10분) 안에 목표 회수율(기본 80%)** 까지 제거하고, 그 모델을 실제 로봇에 적용할 준비까지 하는 것이 목표입니다. AI 로봇은 3대 중 1대를 고르고 나머지는 기존 경로로 함께 일합니다.
> 현재: **v3.0.0 릴리스 준비 완료**(2026-11-06, 태그 보류 — 사용자 결정). 대형 로봇(KR 210) 단독 셀의 스트로크 학습 — 규칙 경로 쓸기 방향(번갈아) 72.9%, 진화 탐색 84.0%(교사), PPO 2차 **74.2%**(현장용, 40회 학습의 40회째 — 2026-11-07 채택 변경, 10회 모델은 71.5%) / 측면 로봇 모드 3 타이밍 밀기 / 앱 학습·재생 패널 / 혼자 학습 `train.bat`. 검토 `REVIEW_v3.0.0.md`, 현황 `STATUS.md`, 진행표 `PROMPTS.md`. 측면 로봇 셀 학습·가상 카메라는 v3.0.1. 이전 버전은 `../v1.1.2/`, `../v1.1.1/`, `../v1.1.0/`, `../v1.0.0/`(이상·고장 데이터는 `../v2.0.0/`).

브라우저에서 바로 실행하는 경량 **산업용 로봇 통합 시뮬레이터**입니다. ABB / KUKA / FANUC / NACHI의 대표 모델 12종을 고르고 조작할 수 있습니다. 자기 충돌·장애물 충돌·특이점 감지와 정지/알람을 제공합니다. A와 B만 지정하면 충돌을 피하는 경로와 중간 경유점을 자동으로 만들어 실행합니다(cuRobo 개념의 경량 버전).

> 모든 로봇은 **근사 모델**입니다. 공개 카탈로그 사양을 바탕으로 6축 구형 손목 표준 구조를 만들었고, 최대 도달거리는 카탈로그 값의 ±5%(실측 ±0.61%) 안에 맞췄습니다. 실제 기구와는 다를 수 있습니다.

## 실행 방법

> **다른 PC(새 노트북)에서 처음 받는 경우**에는 [SETUP.md](SETUP.md)를 따르세요. 준비물, 저장소 받기(공개), v1.0.0 백업본 받기, 동작 확인, Claude Code 연결을 다룹니다.

ES Module과 Web Worker는 `file://` 경로에서 브라우저 보안 정책으로 차단됩니다. 그래서 **로컬 정적 서버로 실행합니다.** 빌드나 설치 과정은 없습니다.

- **Windows:** 이 폴더의 `start.bat`을 더블클릭합니다. `serve.py` 서버가 뜨고 브라우저가 자동으로 열립니다(Python 필요). 검은 창은 서버이므로 사용하는 동안 열어 두세요.
- **Python:** `python serve.py` 실행 후 http://localhost:8300 접속
- v3.0.0은 **포트 8300**, v2.0.0은 8200, v1.1.2는 8112, v1.1.1은 8111, v1.1.0은 8011, v1.0.0은 8000을 씁니다. 포트가 다르면 브라우저 저장 데이터도 분리되므로 여러 버전을 동시에 열어도 섞이지 않습니다.
- **기타 정적 서버:** `npx serve .`, GitHub Pages 등에서도 동작합니다. 업데이트 후에는 브라우저 캐시를 비워야 할 수 있습니다.

Three.js(`three@0.160.0`)와 물리엔진 Rapier(`@dimforge/rapier3d-compat@0.21.0`)는 CDN(jsdelivr)에서 불러오므로 인터넷 연결이 필요합니다. Rapier(약 4 MB)는 물리 모드를 처음 켤 때만 불러옵니다. `index.html`을 직접 열면 실행 방법 안내만 표시됩니다.

`serve.py`가 하는 일:
- 캐시 금지 헤더를 보냅니다.
- 앱을 열 때 사이트의 파일 캐시를 비웁니다(저장 데이터는 유지). 그래서 업데이트 후에도 예전 JS가 섞이지 않습니다.
- 포트가 이미 사용 중이면 알려 줍니다.

## 사용법

### 기본 조작
1. 상단 메이커 배너에서 메이커를 고르고, 왼쪽 모델 카드를 클릭해 로봇을 불러옵니다.
2. 오른쪽 **기능 설정**에서 필요한 안전 감지(자기 충돌 / 장애물 충돌 / 특이점)를 켭니다.
3. **관절 조그**나 **직교 조그**로 로봇을 움직입니다. 위반이 감지되면 로봇이 멈추고 상단에 알람이 뜹니다. **Reset**(또는 `R`)으로 해제합니다.

### 자동 경로 계획 (A → B)
1. 기능 설정에서 **자동 경로 계획**을 켭니다. 충돌 회피를 보려면 **장애물**을 추가하고 **장애물 충돌 감지**도 켭니다.
2. 자동 경로 계획 패널에서 **A(시작)** 와 **B(목표)** 를 지정합니다.
   - A: 현재 자세 / Waypoint / TCP 좌표
   - B: Waypoint / TCP 좌표
3. **경로 생성**을 누르면 다음을 고려한 중간 경유점이 자동으로 만들어집니다. 3D 뷰에 **A·1·2…·B** 라벨로, 패널에 목록으로 표시됩니다.
   - 장애물·자기 충돌 회피(항상)
   - 특이점 회피(옵션, 기본 ON)
   - 도달 범위(Out of Reach)
4. **▶ 실행**을 누릅니다. 로봇이 A에 없으면 충돌을 피해 A로 먼저 이동한 뒤 B까지 움직입니다. **⏮ A로 이동**으로 되돌아갈 수 있습니다.
5. 필요하면 **경유점을 Waypoint 목록에 추가**로 저장합니다(이름: 경로N-A, 경로N-1 … 경로N-B).

### 드로스 제거 셀 (v1.1.1)
사용자 영상(`DrossRemovingRobot.MOV`)과 비슷한 용융 아연 포트의 드로스 제거 작업입니다.
1. **대형 로봇**(IRB 6700, KR 210, R-2000iC, SRA166)을 고릅니다. 다른 로봇이면 패널의 **대형 로봇으로 바꾸기**를 누르세요.
2. 오른쪽 **드로스 제거 셀** 패널에서 **드로스 제거 셀 사용**을 켭니다. 카메라가 셀 보기로 바뀌고, 물리 모드로 전환되며, 그리퍼 대신 **스키머**(수직 봉 + 사각 스쿱)가 달립니다.
3. 포트 욕면에 드로스가 떠 있습니다(스나우트 앞 = 이 로봇의 작업 영역, 너머 = 다른 로봇 영역).
4. **▶ 1사이클**: 드로스가 가장 많은 레인을 골라 레인 접근 → 스쿱 하강 → 스윕 → 상승 → 드로스 박스로 이동 → 기울여 쏟기 → 복귀를 자동으로 계획·실행합니다. 3D 뷰에 경로(보라), 스윕 끝(주황), 쏟기(청록)가 표시됩니다.
5. **⟳ 자동 연속**: 정지·Esc·알람까지 반복합니다. `Space` = 일시정지/계속.
6. 패널 집계: 작업 영역 드로스(개수·kg·덮인 면적), 회수(박스), 흘림, 사이클 시간. **셀 설정**에서 초기 개수·발생률·시드·잠김 깊이·스윕 속도를 바꿉니다. **↺ 다시 배치**는 처음 배치로 되돌립니다.
- 포트 벽·스나우트·드로스 박스는 장애물이라 장애물 감지가 켜져 있으면 닿기 전에 멈춥니다. 드로스는 작업 대상이라 스쿱이 닿아도 됩니다.
- 셀을 끄면 설비·드로스·스키머가 사라지고 그리퍼 설정이 다시 적용됩니다.

#### 측면 로봇 (소형·협동 로봇)
1. 드로스 셀 패널의 **측면 로봇**에서 **왼쪽(L)·오른쪽(R)** 각각 로봇을 고릅니다. 후보: IRB 1200, KR 6, LR Mate, MZ07, UR5e, UR10e, UR20.
2. 역할을 고릅니다.
   - **모드 1 · 제거:** 자기 쪽 바깥 띠(|y| ≥ 470 mm)의 드로스를 작은 스쿱으로 떠서 옆의 측면 드로스 박스에 버립니다. 대형 로봇은 가운데 레인만 맡아 동시에 일합니다.
   - **모드 2 · 보조 밀기:** 밀대로 벽 쪽 드로스를 포트 가운데(대형 로봇 레인)로 밀어 줍니다. 대형 로봇이 포트 밖(드로스 박스)에 있을 때만 들어갑니다.
3. ▶ 1사이클(대형 1사이클 + 측면 각 1작업) 또는 ⟳ 자동 연속. Esc로 모두 멈춥니다.
- 로봇 사이 간섭은 항상 검사합니다. 대형 로봇은 측면 로봇에 닿기 전에 정지·알람하고, 측면 로봇은 다른 로봇이 가까우면 기다립니다.
- 설계·수치는 [../v1.1.1/DROSS_PATH.md](../v1.1.1/DROSS_PATH.md), 그림이 있는 설명은 [../v1.1.1/docs/](../v1.1.1/docs/)의 Word 문서를 보세요.

### 실시간 계측 · 데이터 추출 (v1.1.2)
1. 오른쪽 **실시간 계측 · 데이터** 섹션에서 보고 싶은 항목 버튼을 누릅니다: **각도 / 속도 / 전류 / 토크**. 누른 항목만 3D 화면 왼쪽 위 표에 실시간으로 나오고, 아무것도 누르지 않으면 표가 숨습니다.
2. **표시할 로봇**에서 대형·왼쪽·오른쪽 측면 로봇을 고릅니다. 표의 막대: 각도 = 관절 범위 안 위치(세로선 0°), 속도 = 최대 속도 대비, 전류·토크 = 정격 대비(70%↑ 주황, 90%↑ 빨강).
   - **📈 그래프**를 켜면 3D 화면 아래쪽에 켠 항목마다 J1~J6 시계열 그래프가 나옵니다(최근 5·10·30 s 선택).
3. 데이터가 필요하면 샘플링(10~60 Hz)을 고르고 **● 기록 시작** → 로봇을 운영(조그, 1사이클, 자동 연속 등) → **■ 기록 정지** → **⬇ 엑셀 추출**.
4. 엑셀 시트: `data`(시간대별 로봇별 49열 — 각도·속도·가속도·토크·전류·TCP·단계·사이클·부하·드로스), `cycles`(사이클 요약: 피크·RMS 전류, 에너지, 회수), `events`(단계 변화·알람), `columns`(열 설명), `meta`(설정·모델 가정).
- 전류·토크는 시뮬레이터에 모터 모델이 없어 **근사 동역학으로 추정한 값**입니다(중력 + 관성 + 마찰 + 욕 저항). 실측이 아닙니다. 수식·가정은 `PRD_v.1.1.2.md` 2장과 엑셀 `meta` 시트에 있습니다.
- 머신러닝 과정·과제 아이디어는 `PRD_v.1.1.2.md` 5장.

### 헤드리스 결과 3D 재생 (v3.0.0)
1. 헤드리스로 10분 실행해 기록 파일을 만듭니다(`v3.0.0/` 폴더에서, Node 18+).
   ```bash
   node tools/episode.mjs --config mode1            # KR 210 + 왼쪽 UR10e + 오른쪽 IRB 1200 (모드 1), 시드 11, 600 s
   node tools/episode.mjs --config alone --seed 12  # 대형 단독
   # 옵션: --main <로봇 id> --left ur-ur10e:2 --right none --seed --count --simS --every 0.1 --out <파일>
   ```
   결과는 `results/<날짜>/<시각>_episode_<이름>/*.rsim.json.gz`(10분에 약 0.5 MB)입니다. 옵션 `--config push`(측면 모드 3), `--lane-dir robot|snout|alternate`(대형 쓸기 방향).
2. 앱 오른쪽 패널 **에피소드 재생 → 에피소드 불러오기**에서 그 파일을 고릅니다.
3. 3D 화면 아래 막대로 조작합니다: ⏮ 처음으로, ▶/⏸ 재생·일시정지(**Space**), 배속 0.25~20×, 시간 막대(앞뒤 이동).
   - 오른쪽 위에는 회수율(목표선), 대형 로봇 단계, 고른 로봇의 J1~J6 관절각이 나옵니다.
   - 패널에는 에피소드 정보·최종 결과·회수율 곡선이 나옵니다.
4. **재생 종료**를 누르면 원래 장면으로 돌아옵니다. 재생 중에는 앱 시뮬레이션이 멈추고, 저장된 설정은 바뀌지 않습니다.

기준선 표(규칙 경로 10분 회수율, 대형 4종 × 단독·모드 1·모드 2 × 시드 3개)는 `node tools/baseline.mjs` → `results/<날짜>/<시각>_baseline_<이름>/report.md`.

**결과·문서는 덮어쓰지 않습니다.** 실행할 때마다 `results/<날짜>/<시각>_<종류>_<이름>/` 폴더가 새로 생기고 `results/INDEX.md`에 한 줄씩 쌓입니다(`results/README.md`). 기술 문서도 `docs/<날짜>_<시각>_<제목>/`에 새로 만듭니다(`docs/README.md`).

> **AI 학습 구조를 그림으로 보려면** 최신 판 기술 문서(목록·최신 판 표시는 `docs/README.md`)(계층형 B, 진화 탐색, PPO 절차, 결과, 파일 이름 규칙)를 엽니다. 결과 폴더 안내는 `results/README.md`.

### 학습 (Trial & Error) (v3.0.0)
스쿱의 열린 면 방향(J6), 쓸어 가는 방향, 시작 위치, 스윕 중 회전, 기울임, 깊이, 속도를 바꿔 가며 시도합니다. 내가 정한 점수 규칙으로 가장 좋은 스트로크만 실행합니다(진화 탐색). 학습된 PPO 정책 실행은 아래 "PPO 강화학습".
1. **드로스 제거 셀** 패널에서 대형 로봇·측면 로봇·드로스 개수·시드를 정합니다. 학습은 이 설정을 씁니다.
2. **학습 (Trial & Error)** 패널을 설정합니다.
   - 목표 회수율·제한 시간
   - **점수 규칙**: 회수 +, 벽 띠 보너스 +, 헛질 −, 흘림 −, 시간 −, 계획 불가 −
   - **시도할 범위**: 변수마다 탐색 켜기·최소·최대·고정값
   - 방법·후보 수·세대 수·병렬 Worker
3. **▶ 학습 시작**을 누르면 브라우저 Worker에서 돌고, 학습 진행률 막대(시뮬레이션 시각 ÷ 제한 시간, 경과·남은 시간)·회수율 막대·결정별 최고 점수(규칙 경로 점수와 비교)·스트로크가 표시됩니다.
   - 끝나면 **학습 결과 3D 재생 / 규칙 결과 3D 재생 / 결과 저장**을 쓸 수 있습니다.
4. 큰 학습은 헤드리스로 돌리는 편이 빠릅니다. **설정 내보내기**로 파일을 만든 뒤 아래처럼 실행합니다.
   ```bash
   node tools/train.mjs --lab robosim-lab-*.json          # 또는
   node tools/train.mjs --config alone --seed 11 --population 32 --iterations 4 --workers 14
   ```
   결과는 `results/<날짜>/<시각>_cem_<로봇>-<구성>-s<시드>/`(예: `results/2026-11-05/1552_cem_kr210-alone-s11/`)에 `report.md`(규칙 경로와 비교), `cem-alone-s11.rsim.json.gz`·`rule-alone-s11.rsim.json.gz`(3D 재생 파일), `log.json`(모든 시도)으로 남습니다.

### PPO 강화학습 (v3.0.0)
진화 탐색은 매번 시뮬레이터로 시도해야 해서 실제 로봇에 그대로 쓸 수 없습니다. PPO는 미리 연습해 **드로스 분포만 보고 바로 스트로크를 고르는 정책(신경망)**을 만듭니다.
```bash
node tools/ppo-train.mjs --iterations 40 --bc 3 --workers 14 --name run2    # 학습 (이 PC 약 2시간) → results/<날짜>/<시각>_ppo-train_kr210-run2/
node tools/ppo-eval.mjs --policy results/2026-11-05/1814_ppo-train_kr210-run1/policy-best.json --config push   # 10분 과제 정책 vs 규칙 + 3D 재생 파일 (새 폴더)
```
결과 폴더: `policy-best.json`(최종 채택 정책), `policy-last.json`(마지막 반복), `checkpoints/iter-NNN.json`(5회마다 중간 정책), `train-report.md`·`train-curve.json`(학습 기록), `cell-eval-<구성>.md`(전체 셀 평가).
앱에서는 **학습 (Trial & Error) → 정책 불러오기 (PPO)** 로 `policy-best.json`을 고르고 방법 '학습된 정책 실행'으로 ▶ 학습 시작 → 결과 3D 재생.
결과(KR 210 단독 10분, 평가 시드 11·12·13):
- 1차(규칙 교사, 40회): 정책 65.6%, 규칙 경로(로봇 쪽) 61.3% (`results/2026-11-06/0836_ppo-eval_kr210-run1-alone/cell-eval-alone.md`)
- 2차(진화 탐색 교사, 규칙 레인 기준 조정, 10회): 정책 71.5%, 규칙 경로(번갈아) 72.9%, 진화 탐색 84.0% (`results/2026-11-06/1311_pipeline_kr210-run2/report.md`) — 2026-11-07까지 채택 모델
- 2차 40회(같은 조건, 2026-11-07): 연습장 시험 최고 30회째 76.0%, 실제 셀 68.6% → 채택 안 함. **40회째 모델은 실제 셀 74.2%**(규칙보다 +1.2%p, `results/2026-11-07/1352_ppo-eval_kr210-run3-alone/`) → **지금 채택 모델**: `results/2026-11-07/0947_ppo-train_kr210-run3/policy-last.json` (2026-11-07 사용자 결정). 시드 10개(11~20) 재평가: 72.5% vs 규칙 74.6% (`results/2026-11-07/0947_ppo-train_kr210-run3/NOTE.md`)
- 명령 창 도구는 진행 줄마다 `[████░░░░] 42% · 경과 · 남은 약` 막대를 보여 줍니다.

### 단축키
- `Space`: 재생/일시정지 (계획 경로 시작 자세면 경로 실행, 아니면 Waypoint 재생)
- `Esc`: 정지 (경로 계산 취소, 드로스 자동 연속 정지, 드로어/알람 로그 닫기 포함). 로봇·그리퍼 동작만 멈추며 물리 시뮬레이션은 계속됩니다(물리 일시정지는 상단 `PHYS` 배지 또는 물체 패널의 일시정지)
- `R`: 알람 Reset
- `G`: 그리퍼 열기/닫기 (그리퍼를 켰을 때, 입력창에서 글자를 입력하는 중에는 동작하지 않음)
- 상단 `PHYS ▶ / PHYS ⏸` 배지: 물리 모드에서 누르면 물리 실행/일시정지. 물리 모드에서는 3D 뷰 테두리가 보라색(일시정지면 점선), 움직이는 물체는 보라색 테두리로 표시됩니다.
