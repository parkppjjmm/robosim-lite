### 10분 과제 회수율 (KR 210 대형 단독, 평가 시드 11·12·13 평균)

| 방법 | 회수율 | 근거 |
|---|---|---|
| 규칙 경로 (v1.1.2와 같은 로봇 쪽) | 61.3% | PRD 1.1·1.4 |
| 규칙 경로 (번갈아, [A]) | 72.9% | PRD 1.4 |
| 진화 탐색 (매 스트로크 후보 32개 × 4세대, 교사) | 84.0% | PRD 1.5 — 현장 실시간 사용 불가 |
| PPO 1차 (9개 값 직접, 규칙 교사) | 65.6% | PRD 1.3 |
| **PPO 2차 (규칙 레인 기준 조정, 진화 탐색 교사, 10회)** | **71.5%** | PRD 1.5, `results/2026-11-06/1311_ppo-train_kr210-run2/` (NOTE.md: 10회까지만, 채택 = 5회째) |
| 측면 셀: 모드 2 / 모드 3 타이밍 밀기 (규칙) | 53.3% / 57.5% | PRD 1.4 |

목표 80%는 진화 탐색만 넘었고, 현장용 정책(PPO 2차)은 아직 못 넘었다.

> 추가 (2026-11-07): 2차 PPO를 40회까지 학습(run3)했고, 40회째 모델이 실제 셀 **74.2%**(80.6%·65.6%·76.3%)로 규칙 번갈아(72.9%)를 넘었다. 사용자 결정으로 현장용 채택 모델을 이것으로 바꿨다 — `results/2026-11-07/0947_ppo-train_kr210-run3/policy-last.json` (`results/2026-11-07/1352_ppo-eval_kr210-run3-alone/NOTE.md`). 위 표와 AC-64·65는 릴리스 준비 시점 기록이라 그대로 둔다. 같은 날 시드 10개(11~20)로 다시 평가하니 72.5% vs 규칙 74.6%(−2.0%p)였다 — `results/2026-11-07/1534_ppo-eval_kr210-run3-alone/NOTE.md`.

## 3. 작업 중 발견하고 고친 문제

| 구분 | 내용 | 조치 |
|---|---|---|
| 주요 | 스나우트 쪽 운반 중 드로스가 튀어 나감 | 4단계로 고침: 담은 채 돌리기 → 물러나기(스나우트 충돌) → J6 감김 적은 회전 방향 → 물리 쿼터니언 부호 연속(`continuousRot`, 한 스텝 360° 회전 방지) |
| 주요 | 모드 3 초안(구역 나누기)에서 대형·측면이 30 mm까지 붙어 교착 | 타이밍 밀기로 다시 설계(대형 도착 예정 시각 ≥ 계획 시간 + 1.5 s일 때만 밀기) |
| 주요 | 9개 값 직접 행동은 모방이 잘 안 됨 | 2차: 규칙 레인 기준 조정(잔차) 행동 + 직전 스트로크 관측(102차원) |
| 치명(저장소) | 개인 문서가 공개 저장소에 커밋됨 | 사용자 승인으로 기록 수정·강제 push, `.gitignore` `*현대제철*`, 커밋은 바꾼 파일만 골라서 |
| 경미 | 결과·문서 덮어쓰기 | `results/<날짜>/<시각>_…`, `docs/<날짜>_<시각>_…`, 커밋 앞 `[날짜 시각 KST]` |
| 경미 | 학습 패널 안내문의 `v3.0.0\train.bat`이 "v3.0.0 rain.bat"으로 표시(JS 문자열 `\t`) | 4판 스크린샷 촬영 중 발견해 수정 |
| 시험 | 릴리스 스모크에서 "회수 집계 빈칸"으로 보임 | 회귀 아님: 학습·재생 패널도 `dr-stats` 클래스를 써서 시험이 첫 요소를 읽음 → 선택자 수정 후 통과 |

## 4. 한계 · 하지 않은 것 (이후 버전)

- **v3.0.1로 미룸 (사용자 결정):** N-1 측면 로봇 셀 학습(측면 모드 3 셀의 시범 → PPO → 평가), N-1a 측면 셀에서 스나우트 쪽 쓸기가 측면 로봇과 19 mm까지 가까워지는 문제, N-2 상부 가상 카메라·히트맵.
- **v3.0.0 PRD에 있지만 만들지 않음 → 이후 버전으로 넘김 (사용자 결정 2026-11-06):** R-1 PPO 추가 학습(교사 84%에 가깝게), R-2 안전 필터 `shield.js`, R-3 스킬 실행기·Δq 하위 정책, R-4 ONNX·추론 일치, R-5 앱 AI 패널 나머지, R-6 벤치마크 세트, R-7 측면 로봇 AI 슬롯, R-8 하드웨어 준비, R-9 A 방식 비교.
- 모든 수치는 구형 입자 근사 시뮬레이터 결과다. 실제 드로스(점착·덩어리)와 차이가 가장 크다.
- 평가 시드가 3개라 숫자가 출렁인다(2차 PPO 연습장 시험: 5회째 71.3% → 10회째 62.3%).
- 앱의 "대형 로봇으로 바꾸기" 기본값(ABB IRB 6700)은 측면 로봇이 있으면 덤프 자세를 못 찾는다(기존 한계) → KR 210 사용.
- 하지 않은 시험: 실제 GPU FPS, CDN 차단, 이전 버전 AC-1~29 브라우저 전체 재실행.
