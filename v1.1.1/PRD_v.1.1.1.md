## 1. 개요

### 1.1 범위 변경 (2026-11-05 사용자 결정)
- 원래 계획의 v1.1.1(작업 셀: 컨베이어·공급기·센서·사이클 타임)을 바꿔, v1.1.1은 다음 두 가지로 한다.
  1. **v1.1.0 검토의 경미 이슈 9건(m-2 ~ m-10) 수정** (`../v1.1.0/REVIEW_v1.1.0.md` 2장)
  2. **드로스 제거 작업 셀**: 사용자가 준 영상(`DrossRemovingRobot.MOV`)과 비슷한 환경을 만든다
- 컨베이어·공급기·센서는 이후 버전으로 미룬다(9장). 사이클 타임은 드로스 셀의 스키밍 사이클 시간으로 일부 구현했다.
- v1.1.0은 아직 태그(`v1.1.0`)를 붙이지 않았다(5단계 릴리스 대기). v1.1.1은 v1.1.0 폴더의 현재 코드(커밋 `b55a027` + 인수인계 문서)를 복사해서 시작했고, `v1.1.0/` 폴더는 건드리지 않았다.

### 1.2 영상 분석 (참고 환경)
영상은 위에서 내려다본 3D 시뮬레이션이다. 확인한 요소는 다음과 같다(2초 간격 프레임 12장 + 20초 지점 원본 해상도 1장).

| 영상 요소 | 설명 | v1.1.1 반영 |
|---|---|---|
| 아연 포트(Zinc Pot) | 넓은 직사각형 욕조, 은백색 욕면에 격자 | 포트 벽 4면 + 은회색 욕면(100 mm 격자) |
| 드로스(Dross) | 욕면에 떠 있는 크고 작은 구형 덩어리. 짙은 회색·밝은 회색·황갈색이 섞여 있고, 좌·우 벽 쪽에 많이 쌓여 있음 | 지름 40~90 mm 구 입자, 부력으로 떠 있음, 벽 근처 60% 집중 배치, 3색 계열 |
| 강판·스나우트 | 포트 가운데를 가로지르는 회색 띠(강판이 욕조를 지나가는 구간) | 포트 폭 전체를 가로지르는 스나우트 박스 + 그 위로 올라가는 얇은 강판 |

### 1.3 목표 / 비목표
**목표**
- 경미 이슈 9건을 모두 처리한다(수정 8건 + 문서 정정 1건).
- 드로스가 욕면에 **떠 있고**(부력), 로봇이 스키머로 **떠서 박스에 버리는** 과정을 물리엔진으로 재현한다.
- 레인 선택 → 경로 계획 → 안전 검사 → 실행 → 집계(회수량·흘림·사이클 시간)를 자동으로 반복한다.
- 기존 원칙을 지킨다: 모든 로봇 이동은 적용 전 안전 검사를 통과한다. 시뮬레이션 모드는 전체 단위로만 고른다. 고정 모드·셀 꺼짐 상태는 v1.1.0과 똑같이 동작한다.

**비목표 (v1.1.1에서 하지 않음)**
- 주행축(7축)·다중 로봇 협조, 상부 로봇: 영상에는 있지만 이 앱은 로봇 1대·고정 베이스 구조라 이후 버전 후보로 둔다.
- 실제 CGL 설비 치수·드로스 물성의 정밀 재현: 근사값을 쓴다(6.2).
- 액체(용융 아연)의 유동 해석: 부력과 점성 저항만 근사한다.

## 3. 기능 요구사항 — 드로스 제거 작업 셀 (FR-25 ~ FR-30)

### FR-25 셀 사용과 배치 (P0)
- 새 패널 **드로스 제거 셀 (Dross Cell)**의 스위치로 켜고 끈다. 저장 위치 `cell.dross.enabled`.
- **대형 로봇(도달거리 2.4 m 이상)에서만 활성**: IRB 6700, KR 210, R-2000iC, SRA166. 다른 로봇이면 안내와 "대형 로봇으로 바꾸기"(같은 메이커의 대형 로봇) 버튼을 보인다.
- 켜면 셀 보기 카메라로 이동하고, 고정 모드면 물리 모드로 전환을 요청한다.
- 고정 설비(로봇 좌표, mm): 포트 안쪽 X 1100~3700 · Y −900~900, 벽 두께 100, 높이 800 / 스나우트 X 2300~2500, Z 560~1200(포트 폭 전체) / 드로스 박스 X 250~950 · Y −1650~−1050, 높이 550, 벽 40.
- 설비는 **고정 모드·물리 모드 모두** 안전 검사·경로 계획의 장애물이고, 물리 모드에서는 고정 바디다. 물체 목록에는 나오지 않고 편집할 수 없다(셀 정의 = 코드 상수).
- 로봇을 바꾸거나 셀을 켜고 끄면 설비·툴·물리 월드를 다시 만든다.

### FR-26 드로스와 욕면 (P0)
- 욕면 높이 Z = 700 mm. 욕면 영역(포트 안쪽)에서 수면 아래로 잠긴 입자에 **부력**(용융 아연 6,600 kg/m³ × 잠긴 구면 캡 부피 × g)과 **점성 저항**(잠긴 비율에 비례, 10 s⁻¹)을 준다.
- 드로스 = 지름 40~90 mm 구, 밀도 3,800 kg/m³(약 60% 잠김). 작업 영역(스나우트 앞)에 `count`개, 스나우트 너머에 `count/2`개(장면 재현용)를 겹치지 않게 놓는다. 60%는 벽 근처 350 mm 띠에 몰린다.
- **발생률**(개/분, 0~120): 시뮬레이션 시간에 따라 작업 영역 욕면에 새 드로스를 떨어뜨린다(최대 800개).
- **같은 시드 → 같은 배치·같은 발생 순서**(결정성). 리셋('다시 배치')하면 새 물리 월드에서 처음 배치로 돌아간다.
- 드로스는 작업 대상이라 안전 검사의 장애물이 아니다(스쿱이 닿아도 됨). 물체 목록·장애물 감지와 별개로 관리한다.

### FR-27 스키머 툴 (P0)
- 셀이 활성이면 그리퍼 대신 **스키머**가 달린다: 수직 봉(길이 700, 지름 50) + 사각 스쿱(360 × 360, 바닥판 10, 뒤·좌·우 턱 높이 80, 앞쪽(+X 툴)은 열림). TCP = 바닥판 윗면 중심.
- 안전 검사 형상: 봉 캡슐 1개 + 스쿱을 덮는 X방향 캡슐 3개(반경 80 → 턱 끝·바닥판 아랫면·판 폭을 모두 덮는 보수적 모델). 링크 번호 7, 알람 표시 이름 "스키머 (봉·스쿱)".
- 물리 형상: 봉 캡슐 + 스쿱 박스 4개(운동학 바디) → 드로스를 실제로 떠서 담는다.
- 개폐 동작이 없다: 그리퍼 열기/닫기·G 키·Waypoint 열기/닫기 동작은 안내 후 건너뛴다. Pick & Place는 "스키머 툴로는 할 수 없습니다"로 거부. 그리퍼 패널은 안내만 보이고 스위치는 비활성.

### FR-28 스키밍 사이클 (P0)
- **레인**: 스쿱 폭 × 0.85 간격으로 Y를 나눈 직선(대형 로봇 기본 6개). 시작 X = 스나우트 앞 − 스쿱 반폭 − 여유, 끝 X = 포트 앞벽 + 스쿱 반폭 + 여유(여유 = 장애물 여유거리 + 30 mm).
- **레인 선택**: 레인 띠 안의 욕면 드로스 수가 가장 많은 레인(같으면 직전 레인에서 먼 쪽).
- **구간**: ① 레인 시작 위(욕면 + 120 mm)로 이동 ② 하강(욕면 − 잠김 깊이, 기본 60 mm) ③ 스윕(포트 앞벽 쪽으로 당김, 기본 120 mm/s) ④ 상승(Z 980) ⑤ 드로스 박스 위로(수평 유지, 150 mm/s) ⑥ 덤프 높이로 하강 ⑦ 열린 앞쪽이 아래로 가게 105° 기울여 쏟기 ⑧ 대기 1.2 s ⑨ 수평 복귀.
- ①은 직선 → (높이를 올린) 직선 3구간 → 경로 계획(RRT, Worker) 순으로 시도한다. 나머지는 직선 보간(⑦·⑨는 실패 시 관절 보간)이며, 모든 구간을 **실행 기준 여유거리로 세분 검사**한다. 덤프 방향은 로봇에서 멀어지는 방향부터 8방향을 차례로 시도한다.
- 실행은 기존 단계 실행(`runSteps`)으로 하므로 모든 이동이 적용 전 안전 게이트를 통과한다. 위반이면 정지·알람.
- **1사이클 / 자동 연속**: 자동 연속은 정지·Esc·알람·실패까지 반복한다. 작업 영역이 비면 발생률 > 0일 때 5 s(시뮬레이션 시간)씩 기다렸다가 다시 보고, 0이면 끝낸다.
- 계획 중·실행 중에는 모드 전환·리셋·로봇 변경·셀 켜기/끄기를 막는다(`robotBusy`). Space = 일시정지/계속, Esc = 정지.

### FR-29 집계 표시 (P0)
- 1초마다: 작업 영역 욕면 드로스(개수·kg·덮인 면적 %), 회수(드로스 박스 안, 개수·kg), 흘림(포트·박스 밖 바닥), 운반 중, 스나우트 너머, 사이클 수·최근/평균 사이클 시간(시뮬레이션 시간), 발생 누적.

### FR-30 설정과 저장 (P1)
- 설정: 초기 드로스(0~400), 발생률(0~120 개/분), 난수 시드(1~99999), 스쿱 잠김 깊이(20~75 mm), 스윕 속도(30~250 mm/s).
- 발생률·잠김 깊이·스윕 속도는 바로 반영, 초기 개수·시드는 '다시 배치' 때 반영(안내).
- 저장: `cell.dross` (6장). 새로고침하면 셀·설정이 복원되고 물리 모드면 드로스를 처음 배치로 다시 놓는다(시뮬레이션 상태는 저장하지 않음 — v1.1.0 배치/상태 분리 원칙과 같음).

## 3-2. 기능 요구사항 — UR 협동 로봇 · 측면 로봇 (FR-31 ~ FR-36, 2026-11-05 추가 요청)

> 사용자 요청: "UR 로봇 시리즈 3개 추가(UR10e 필수), 소형 로봇(협동 로봇 포함)도 드로스 제거를 수행 — 영상처럼 측면에 각 1대씩(기존 대형 로봇은 유지), 측면 로봇은 각각 선택해서 불러오고, 역할을 두 모드로 선택: 모드 1 = 드로스를 퍼내는 제거 작업까지, 모드 2 = 대형 로봇이 잘 퍼낼 수 있도록 대형 로봇 근처로 밀어 주기만"

### FR-31 UR 협동 로봇 3종 (P0)
- 메이커 배너에 **UR** 추가, 모델 3종: **UR5e**(5 kg, 850 mm, 소형), **UR10e**(12.5 kg, 1300 mm, 중형), **UR20**(20 kg, 1750 mm, 중형). `robots.json`에 `cobot: true`.
- 다른 모델과 같은 규칙의 **근사 모델**이다. UR은 실제로 오프셋 손목(비구형)이지만 이 앱의 6축 구형 손목 구조로 근사했다. 어깨 높이(d1)·상완 길이는 공개 사양, 전완 길이는 카탈로그 도달거리(J1 축 → 손목 중심 최대 수평거리)가 ±5% 안에 들도록 정했다(UR5e 430, UR10e 690, UR20 888 mm). 관절 범위 J1·J4~J6 ±360°, J2 ±150°, J3 ±160°, 관절 속도는 공개 사양.
- 실제 UR은 상완이 어깨 오프셋만큼 옆으로 나가 베이스와 닿지 않으므로, 근사에서 생기는 베이스↔상완(0-2) 자기 충돌 오탐을 협동 로봇에서는 검사하지 않는다(`collision.js buildSelfPairs`).
- 일반 기능(조그, 안전 감지, 경로 계획, 그리퍼, Pick & Place)은 다른 모델과 같다.

### FR-32 측면 로봇 배치와 선택 (P0)
- 드로스 셀이 켜져 있을 때(대형 로봇 필요) 패널의 **측면 로봇** 영역에서 **왼쪽(L)·오른쪽(R)** 각각 로봇을 고른다: 없음 / 소형 4종(IRB 1200, KR 6, LR Mate, MZ07) / UR 3종.
- 자리: 포트 좌·우 벽 바깥 **받침대**(400 × 400, 높이 800 = 포트 테두리 높이) 위. 베이스 (1700, ±1250, 800), 로봇 정면이 포트 안쪽을 보도록 Z축 회전(왼쪽 −90°, 오른쪽 +90°).
- 받침대는 다른 로봇에게는 장애물이다(자기 받침대는 자기 검사에서 제외).
- 설치하면 **대기 자세(park)**(자기 쪽 포트 벽 위, 툴 아래)를 IK로 찾아 그 자세로 놓고, 닿을 수 있는 **레인을 미리 계산**한다(도달·충돌 가능한 구간만).
- 측면 로봇마다 툴이 정해진다: 모드 1 = **작은 스키머**(봉 350, 스쿱 200 × 200, 턱 50), 모드 2 = **밀대**(봉 350, 날 300 폭 × 120 높이 × 8 두께).
- 저장: `cell.dross.sides = { left: { robotId, mode }, right: { robotId, mode } }`. 새로고침하면 다시 설치된다.

### FR-33 모드 1 — 드로스 제거 (구역 분할 동시 작업)
- 포트를 Y 방향으로 나눈다: **|y| < 470 mm = 대형 로봇**, **|y| ≥ 470 mm = 그쪽 측면 로봇**(경계 양쪽 여유 60 mm).
  - 대형 로봇 레인: 그쪽에 모드 1 측면 로봇이 있으면 레인 중심 |y| ≤ 470 − 60 − 180 = 230 (양쪽 다 있으면 −230, 0, +230 세 레인).
  - 측면 로봇 레인: 레인 중심 |y| = 630, 750 (작은 스쿱 반폭 100), X는 1400~2150 중 닿는 구간. **−X 방향으로 스윕**(대형과 같은 방향).
- 측면 로봇 사이클 = 대형과 같은 템플릿(접근 → 하강 45 mm → 스윕 120 mm/s → 상승 → 자기 **측면 드로스 박스** 위 → 기울여 쏟기 → 복귀).
- 측면 박스(380 × 380, 높이 450): 받침대 옆(포트 밖), 베이스에서 +X로 **로봇별 거리** — 덤프 자세가 나오는 거리를 미리 계산한 표(`SIDE_BIN_TABLE`). IRB 1200·KR 6·UR10e 750 mm, LR Mate·MZ07·UR5e 650 mm, **UR20은 없음(모드 1 불가 → 모드 2만)**.
- 대형과 측면이 **동시에** 일한다(공간이 나뉘어 있으므로 잠금 없음).

### FR-34 모드 2 — 보조 밀기 (포트 점유 잠금)
- 측면 로봇은 밀대로 **벽 쪽 드로스를 포트 가운데(대형 로봇 레인)로 밀어 준다**.
  - 밀기 레인: X = 1300·1500·1700·1900·2100 중 닿는 것.
  - 밀기 구간: 벽 쪽 |y| 790에서 시작해 |y| 250(목표) 또는 도달 한계까지.
  - 1스트로크 = 시작점 위 접근 → 날 하강(욕면 −70) → 밀기 150 mm/s → 상승 → 대기 자세로 복귀.
- 밀기 구간이 대형 로봇 레인과 겹치므로 **포트 점유 잠금**으로 시간을 나눈다.
  - 대형 로봇: 사이클을 계획할 때 `wantsPot = true` → 레인 접근 전에 "측면 로봇이 포트에서 나오길 대기" → 스쿱을 들어 올린 뒤 `wantsPot = false`(드로스 박스로 가는 동안 포트를 비워 줌).
  - 모드 2 측면 로봇: `wantsPot`이 false일 때만 새 스트로크를 시작한다. 계획 중·실행 중에는 "포트 안"으로 친다.
- 밀 드로스가 없으면(레인 띠 안 0개) 3 s 뒤 다시 본다.

### FR-35 로봇 간 간섭 (P0, 항상 켜짐)
- **대형 로봇:** 적용 전 안전 검사에 측면 로봇의 현재 형상(캡슐)을 넣는다(`ctx.others`). 감지 토글과 관계없이 항상 검사하고, 여유거리 안이면 정지·알람("링크 ↔ 왼쪽 측면 로봇 (UR10e)").
- **측면 로봇:** 매 스텝 자기 정적 검사(로컬 좌표) 뒤, 다른 로봇과 (여유거리 + 30 mm)보다 가까워지면 **그 자리에서 기다린다(양보)**. 20 s 넘게 풀리지 않으면 알람.
- **시작 전 경로 확인:** 측면 로봇은 계획한 경로 전체가 지금 다른 로봇 자세와 (여유거리 + 30 mm) 이상 떨어져 있을 때만 시작한다 → 서 있는 로봇의 길을 막아 서로 기다리는 교착을 막는다.
- 측면 로봇 이동 중 정적 위반(설비·자기 충돌)은 알람(측면 로봇 하이라이트).

### FR-36 실행·표시
- ▶ 1사이클 = 대형 1사이클 + 측면 로봇 각 1작업, ⟳ 자동 연속 = 모두 반복, ■ 정지·Esc = 모두 정지, Space = 일시정지(측면 포함), 알람 = 모두 정지.
- 측면 로봇 상태(계획 중/단계명/간섭 회피 대기/포트 대기), 작업 횟수, 레인 수, 측면 박스 회수 수, 박스별 회수(대형·왼쪽·오른쪽)를 패널에 표시. 3D 뷰에 받침대(노랑), 측면 박스, 로봇 위 L/R 표시.
- 측면 로봇 구성 변경은 정지 중·알람 없을 때만. 바꾸면 설비(받침대·측면 박스)가 바뀌므로 물리 월드를 새로 만든다(드로스도 처음 배치).

## 4. 기존 기능과의 관계
- **셀 꺼짐**: 설비·드로스·스키머가 없고 v1.1.0과 같다. 저장 데이터에 `cell.dross`가 없으면 꺼짐 + 기본값.
- **안전 감지**: 설비는 일반 장애물과 같은 규칙(장애물 감지 ON이면 닿기 전 정지). 자기 충돌 검사에 스키머가 포함된다(전완 ↔ 툴). 물리 모드 규칙(손가락 접촉 허용)은 스키머에는 해당하지 않는다(스키머는 링크 7).
- **경로 계획**: 설비가 장애물로 들어간다. 그리퍼 대신 스키머 형상으로 계획한다.
- **물리 모드 편집(m-3)**: 사용자 물체는 v1.1.0처럼 추가할 수 있고, 드로스·설비와 함께 시뮬레이션된다.

### 6.2 근사와 근거
- 부력은 구면 캡 잠긴 부피로 계산한 충격량을 스텝마다 준다(Rapier에는 유체가 없음). 점성 저항으로 출렁임을 줄여 1 s 이동량 0 mm 수준으로 떠 있다.
- 스쿱은 판이 드로스 아래로 미끄러져 들어간 뒤 뒤 턱이 밀어 모으고, 들어 올리면 판 위에 남는 방식으로 떠진다(영상의 국자 동작 근사). 앞쪽이 열려 있어 기울이면 쏟아진다.
- 설비·드로스 치수, 드로스 밀도·크기, 아연 밀도는 대표값이다(실제 라인 데이터 아님).
