# RoboSim Lite

브라우저에서 바로 실행하는 경량 **산업용 로봇 통합 시뮬레이터**입니다. ABB / KUKA / FANUC / NACHI의 12개 모델(근사 모델)을 고르고 조작합니다. 자기 충돌·장애물 충돌·특이점 감지와, A·B만 지정하면 충돌을 피해 중간 경유점을 자동 생성하는 경로 계획을 제공합니다. v1.1.0부터는 물리엔진으로 물체의 중력·충돌을 시뮬레이션하고, v1.1.1에는 용융 아연 포트의 **드로스 제거 작업 셀**이 있습니다.

- 설치·빌드 없이 실행: Vanilla JavaScript(ES Modules) + Three.js, v1.1.0은 Rapier 추가(모두 CDN)
- 모든 계산(기구학, 충돌, 경로 계획, 물리)은 사용자 브라우저 안에서 수행되며, 서버·API 키·과금이 없습니다.

## v1.0.0 — 기구학 시뮬레이터 (고정본)

### 역할
- 첫 공개 버전이자 **영구 백업**입니다. 이후 버전에서 문제가 생기면 언제든 이 상태로 돌아가 비교·실행할 수 있습니다.
- 내용은 Git 태그 `v1.0.0`과 같습니다(파일 29개 일치 확인). 태그와 브랜치 `backup/v1.0.0`도 함께 보존합니다.
- **수정하지 않습니다.** 버그 수정이나 기능 추가는 새 버전 폴더에서 합니다.

### 시뮬레이션 방식
**기구학 시뮬레이터**입니다. 관절 각도로 로봇 자세를 계산하고, 링크와 물체가 **겹치는지만** 검사합니다. 중력·질량·힘은 없고, 장애물은 항상 배치한 자리에 고정됩니다.

### 기능
| 영역 | 내용 |
|---|---|
| 로봇 선택 | 4개 메이커 배너 → 모델 카드 3종(실루엣 썸네일, 사양, "근사 모델" 배지) → 3D 로드. 12개 모델의 도달거리는 카탈로그 대비 ±0.61% 이내 |
| 조작 | 관절 조그(한계 근접 색 표시), 직교 조그(월드/툴, DLS IK), TCP 실시간 표시 |
| Waypoint | 저장·이름 변경·순서 변경, 관절(PTP)/직선(LIN) 보간 재생, 속도 10 ~ 200% |
| 장애물 | 박스·구·원기둥, 수치 입력·3D 기즈모 편집, 표시/숨김, 바닥 충돌 |
| 안전 감지 (각각 ON/OFF) | 자기 충돌·장애물 충돌(캡슐 근사), 손목·팔꿈치·어깨 특이점. 움직이기 **전에** 검사해서 위반이면 정지·알람, Reset으로만 해제, 알람 로그 100건 |
| 자동 경로 계획 | A·B만 지정 → 다중 해 IK → RRT-Connect → Shortcut → CHOMP 스타일 최적화 → 모서리 블렌딩. 장애물·자기 충돌 회피, 특이점·도달 범위(Out of Reach) 고려, 중간 경유점 자동 생성·라벨 표시, A로 자동 접근 후 실행. Web Worker에서 계산 |
| 데이터 | 브라우저 자동 저장·복원, 손상 데이터 복구, JSON 내보내기/가져오기/초기화 |
| UI | 다크/라이트 테마, 접이식 섹션, 좁은 화면 드로어, 단축키(Space/Esc/R) |
| 실행 환경 | `start.bat` → `serve.py`(캐시 금지, 사이트 캐시 비우기, 포트 중복 감지) |

- v1.1.1 폴더의 코드를 복사해서 시작했습니다(`v1.1.1/`은 수정하지 않음). 요구사항은 `v1.1.2/PRD_v.1.1.2.md`, 작업 기록은 `v1.1.2/WORKLOG.md`.
- **실시간 계측:** 버튼(각도·속도·전류·토크)으로 켠 항목만 J1~J6 값을 3D 화면에 표시. 막대와 시계열 그래프(최근 5·10·30 s). 대형·측면 로봇을 골라 볼 수 있습니다. 전류·토크는 근사 동역학 **추정값**입니다.
- **데이터 기록·엑셀 추출:** 시간대별·상황별(단계·사이클·레인·알람·부하) 49열 기록 → `.xlsx`(시트 data·cycles·events·columns·meta). 머신러닝 기반 데이터용입니다.
- **머신러닝 계획:** PRD 5장(과제 후보·과정·첫 실험 레시피). 실제 구현(고장 주입, 대량 데이터 생성, 학습)은 v2 단계(머신러닝·AI 활용)로 넘겼습니다.

## v2.0.0 — 이상·고장 데이터 생성과 상황 조건부 이상 경계 학습 (개발 중)

### 역할
- v1.1.2 코드를 그대로 복사해 뼈대로 삼은 개발 폴더입니다(`v1.1.2/`은 수정하지 않음). 요구사항 `v2.0.0/PRD_v.2.0.0.md`, 진행표 `v2.0.0/PROMPTS.md`.
- 목표:
  - 시뮬레이터에서 이상 상황을 만들고 라벨을 자동으로 붙입니다. 운전 이상(충돌 근접·관절 한계·특이점·게이트 차단·대기·흘림)과 고장(마찰·과부하·센서 잡음·드리프트)을 다룹니다.
  - 몬테카를로 시나리오 생성기로 데이터를 대량으로 만듭니다.
  - 자세·속도·부하·단계에 따라 달라지는 **조건부 정상 범위(threshold)** 를 학습하고 고정 threshold와 비교합니다.
  - 결과를 앱의 그래프 밴드·경보로 보여 줍니다.
- 상태: 0단계(폴더·문서 준비) 완료. 기능은 아직 v1.1.2와 같습니다.

## 실행

1. 실행할 버전 폴더로 들어갑니다.
2. **Windows:** `start.bat`을 더블클릭합니다. **macOS/Linux:** `python3 serve.py`를 실행합니다(Python 필요).
3. 브라우저가 열립니다. v1.0.0은 http://localhost:8000, v1.1.0은 http://localhost:8011, v1.1.1은 http://localhost:8111, v1.1.2는 http://localhost:8112, v2.0.0은 http://localhost:8200입니다.
   - 포트가 달라서 여러 버전을 동시에 열어도 저장 데이터가 섞이지 않습니다.
   - 이전 버전에서 만든 장면은 데이터 관리의 내보내기 → 새 버전에서 가져오기로 옮길 수 있습니다(v1.0.0 장면은 고정 모드로 열림).

새 PC에서 처음 받는 경우(설치, 저장소 받기, 동작 확인, Claude Code 연결)는 [v1.1.2/SETUP.md](v1.1.2/SETUP.md)를 따르세요.
