# RoboSim Lite

브라우저에서 바로 실행하는 경량 **산업용 로봇 통합 시뮬레이터**입니다. ABB / KUKA / FANUC / NACHI의 12개 모델(근사 모델)을 고르고 조작합니다. 자기 충돌·장애물 충돌·특이점 감지와, A·B만 지정하면 충돌을 피해 중간 경유점을 자동 생성하는 경로 계획을 제공합니다. v1.1.0부터는 물리엔진으로 물체의 중력·충돌을 시뮬레이션합니다.

- 설치·빌드 없이 실행: Vanilla JavaScript(ES Modules) + Three.js, v1.1.0은 Rapier 추가(모두 CDN)
- 모든 계산(기구학, 충돌, 경로 계획, 물리)은 사용자 브라우저 안에서 수행되며, 서버·API 키·과금이 없습니다.

## v1.0.0 — 기구학 시뮬레이터 (고정본)

### 역할
- 첫 공개 버전이자 **영구 백업**입니다. 이후 버전에서 문제가 생기면 언제든 이 상태로 돌아가 비교·실행할 수 있습니다.
- 내용은 Git 태그 `v1.0.0`과 같습니다(파일 29개 일치 확인). 태그와 브랜치 `backup/v1.0.0`도 함께 보존합니다.
- **수정하지 않습니다.** 버그 수정이나 기능 추가는 새 버전 폴더에서 합니다.

### 시뮬레이션 방식
**기구학 시뮬레이터**입니다. 관절 각도로 로봇 자세를 계산하고, 링크와 물체가 **겹치는지만** 검사합니다. 중력·질량·힘은 없고, 장애물은 항상 배치한 자리에 고정됩니다.

### 기능
| 영역 | 내용 |
|---|---|
| 로봇 선택 | 4개 메이커 배너 → 모델 카드 3종(실루엣 썸네일, 사양, "근사 모델" 배지) → 3D 로드. 12개 모델의 도달거리는 카탈로그 대비 ±0.61% 이내 |
| 조작 | 관절 조그(한계 근접 색 표시), 직교 조그(월드/툴, DLS IK), TCP 실시간 표시 |
| Waypoint | 저장·이름 변경·순서 변경, 관절(PTP)/직선(LIN) 보간 재생, 속도 10 ~ 200% |
| 장애물 | 박스·구·원기둥, 수치 입력·3D 기즈모 편집, 표시/숨김, 바닥 충돌 |
| 안전 감지 (각각 ON/OFF) | 자기 충돌·장애물 충돌(캡슐 근사), 손목·팔꿈치·어깨 특이점. 움직이기 **전에** 검사해서 위반이면 정지·알람, Reset으로만 해제, 알람 로그 100건 |
| 자동 경로 계획 | A·B만 지정 → 다중 해 IK → RRT-Connect → Shortcut → CHOMP 스타일 최적화 → 모서리 블렌딩. 장애물·자기 충돌 회피, 특이점·도달 범위(Out of Reach) 고려, 중간 경유점 자동 생성·라벨 표시, A로 자동 접근 후 실행. Web Worker에서 계산 |
| 데이터 | 브라우저 자동 저장·복원, 손상 데이터 복구, JSON 내보내기/가져오기/초기화 |
| UI | 다크/라이트 테마, 접이식 섹션, 좁은 화면 드로어, 단축키(Space/Esc/R) |
| 실행 환경 | `start.bat` → `serve.py`(캐시 금지, 사이트 캐시 비우기, 포트 중복 감지) |

## v1.1.0 — 물리엔진 통합 (개발 중)

### 역할
- v1.0.0 위에 **물리 시뮬레이션**을 더하는 개발 폴더입니다. 요구사항은 `PRD_v.1.1.0.md`이고, 여기에 없는 부분은 `v1.0.0/PRD.md`를 따릅니다.
- **고정 모드에서는 v1.0.0과 똑같이 동작해야 합니다.** 단계마다 v1.0.0 수용 기준 AC-1~10을 다시 확인합니다.
- 완성되면 태그 `v1.1.0`으로 릴리스하고, 이후 그 태그도 수정하지 않습니다.

### 시뮬레이션 방식
시뮬레이션 전체를 두 모드 중 하나로 실행합니다. 물체마다 따로 고르지 않습니다.
- **고정 모드:** v1.0.0과 같습니다. 물체는 배치 위치에 고정됩니다.
- **물리 모드:** 모든 물체에 중력과 충돌 반응을 적용합니다.
- 로봇은 위치 제어로 움직이고(힘에 밀리지 않음), 이동은 항상 안전 검사를 먼저 통과해야 합니다.

## 실행

1. 실행할 버전 폴더로 들어갑니다.
2. **Windows:** `start.bat`을 더블클릭합니다. **macOS/Linux:** `python3 serve.py`를 실행합니다(Python 필요).
3. 브라우저가 열립니다. v1.0.0은 http://localhost:8000, v1.1.0은 http://localhost:8011입니다.
   - 포트가 달라서 두 버전을 동시에 열어도 저장 데이터가 섞이지 않습니다.
   - v1.0.0에서 만든 장면은 데이터 관리의 내보내기 → v1.1.0에서 가져오기로 옮길 수 있고, 고정 모드로 열립니다.

새 PC에서 처음 받는 경우(설치, private 저장소 로그인, 동작 확인, Claude Code 연결)는 [v1.1.0/SETUP.md](v1.1.0/SETUP.md)를 따르세요.

## 버전 규칙

- **v1.0.0은 영구 보존합니다.** `v1.0.0/` 폴더, 태그 `v1.0.0`, 브랜치 `backup/v1.0.0`은 수정·삭제하지 않습니다.
- 새 버전은 자기 폴더에서 개발하고, 완성되면 같은 이름의 태그(`v1.1.0` 등)로 릴리스합니다. 릴리스한 태그는 이후 수정하지 않습니다.
- `main` 브랜치의 커밋 기록은 2026-10-27에 이 폴더 구조로 새로 시작했습니다. 그 이전의 기록은 태그 `v1.0.0`과 브랜치 `backup/v1.0.0`에 남아 있습니다.
- Claude Code로 작업할 때의 규칙은 [CLAUDE.md](CLAUDE.md)에 있습니다.
