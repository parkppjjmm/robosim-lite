  - **시뮬레이션 모드(고정/물리)를 전체 단위로 선택**하는 스위치를 물체 패널 상단에 추가(물체별 선택 없음). 상단 바 `STATIC`/`PHYS` 배지, 상태바 물리 계산 시간.

  - 물리 모드 전환 시 장애물 충돌 감지가 켜져 있으면 안내(세션당 1회, 토글은 그대로).
  - 물체 물성 편집: 밀도 또는 질량, 마찰, 반발(맞닿은 두 면의 평균으로 적용).
  - 물리 모드의 안전 검사와 경로 계획은 배치가 아니라 **현재 물체 위치**를 사용합니다.
  - 저장 스키마 v2(`settings.simMode`, `settings.gravity`, `obstacles[].physics`, `cell`)와 v1 → v2 자동 변환. v1.0.0 데이터·내보낸 JSON은 고정 모드로 열립니다.
  - `tests/physics.mjs`: 낙하·안착, 적층, 결정성, 물성, 범위 이탈, 회전 변환, 50개 성능, 스키마 변환 (15개 항목).
- **물리엔진 통합 1-B (PRD_v.1.1.0 FR-19, 4.3, 4.4, NFR-9·10):**
  - 로봇 링크를 Rapier 운동학 바디(캡슐, CCD)로 등록 → 로봇이 물체를 밀어내고, 로봇 자신은 밀리지 않습니다. 로봇 모델을 바꾸면 다시 등록합니다.
  - 물리 모드 안전 감지: 장애물 충돌 감지 ON이면 그 순간의 물체 위치 기준으로 닿기 전에 정지·알람, OFF이면 물체를 밀어냅니다. 물체 패널에 현재 동작(정지 / 밀어냄)을 표시합니다.
  - **외부 물체 충돌 알람:** 움직이는 물체가 정지한 로봇의 여유거리 안으로 들어오면 정지·알람, 로그에 "외부 물체 충돌".
  - 물리 모드에서 계획한 뒤 물체가 20 mm 이상 움직이면 "다시 생성 권장" 표시.
  - 성능: 물체 위치 정보 재사용(할당 감소), 움직이는 물체가 없으면 외부 충돌 재평가 생략. 상태바 물리 시간이 4 ms를 넘으면 빨간색.
  - `tests/physics.mjs`에 4개 항목 추가(로봇 캡슐 자세, 박스 밀어내기, 로봇 비밀림, 미는 시나리오 결정성) → 총 19개.
- **그리퍼 · TCP · 파지/놓기 2-A (PRD_v.1.1.0 FR-21, FR-22):**
  - 평행 2지 그리퍼(근사 형상). 로봇 크기별 기본 치수 3종(소·중·대형)과 로봇 모델별 사용자 수정, "기본값으로 되돌리기". 저장 위치 `settings.gripper { enabled, overrides }` (검증 포함).
  - 새 패널 **그리퍼 (Gripper)**: 사용 스위치, 열기/닫기, 상태(열림 / 닫힘 / 여는 중 / 닫는 중 / 파지 중: 물체명), 치수 입력. 단축키 G(ㅎ): 열기/닫기.
  - **TCP 오프셋:** 그리퍼를 켜면 TCP가 손가락 끝으로 바뀌어 TCP 표시, 직교 조그(월드/툴), 직선 보간 재생, Waypoint 마커, 경로 미리보기, 자동 경로 계획의 TCP 목표가 모두 새 TCP 기준으로 동작합니다. 저장된 Waypoint(관절값)는 그대로입니다.
  - 그리퍼 형상을 자기 충돌(전완–그리퍼)·장애물 충돌·경로 계획·궤적 최적화에 포함. 물리 모드에서는 손가락이 물체에 닿아도 됩니다(PRD 4.3).
  - **파지/놓기 (물리 모드):** 닫을 때 손가락 사이에 들어가는 물체가 있으면 그 폭까지 닫고 파지 → 로봇과 함께 이동, 열면 놓기(그리퍼 속도를 이어받아 떨어짐). 질량 한계를 넘으면 "파지 실패: 질량 초과", 물체가 없으면 "빈 손 닫힘". 고정 모드는 개폐만 하고 안내합니다.
  - 파지한 물체도 로봇의 일부로 다른 물체·바닥과의 충돌을 검사합니다(집을 때 맞닿아 있던 받침은 떨어질 때까지 제외).
  - 손가락 개폐 중 충돌이 생기거나 깊어지면 정지·알람 "그리퍼 동작 중 충돌".
  - 모드 전환·리셋·로봇 변경·그리퍼 끄기 시 파지를 해제합니다. 그리퍼 설정 변경은 로봇 정지 중·알람이 없을 때만 가능합니다.
  - `tests/gripper.mjs` (30개 항목): 기본값·수정, 형상, 파지 후보, 12개 모델 홈 자세 오탐 없음, 전완–그리퍼 감지, TCP 직선 보간, 플래너 TCP 목표, 파지 물체 검사, 물리 파지 → 들기 → 이동 → 놓기 → 착지, 질량. `run-all.mjs`에 추가.
- **Waypoint 동작 · Pick & Place 2-B (PRD_v.1.1.0 FR-23, FR-24):**
  - Waypoint 도착 동작: 없음 / 그리퍼 열기 / 닫기 / 대기(초). 목록에서 편집하고 아이콘으로 표시합니다. 시퀀스 재생 시 도착 → 동작 → 다음 Waypoint 순서로 진행하며, 일시정지·정지·알람이면 동작도 멈춥니다. "현재 자세 저장" 시 그리퍼가 닫혀 있으면 '닫기'를 제안합니다. 저장 형식 `waypoints[].action`(기본 none).
  - 자동 경로 계획에 작업 유형 **Pick & Place** 추가: 집을 물체, 놓을 위치(TCP 좌표 또는 Waypoint), 파지 방향(위에서 수직 / 현재 방향 유지), 접근 높이(기본 100 mm)만 지정하면 접근 → 직선 하강 → 닫기 → 직선 상승 → 운반(파지 물체 포함 충돌 회피) → 직선 하강 → 열기 → 직선 상승을 자동 생성합니다(`js/task.js`).
  - 실패 시 구간명과 원인을 표시합니다(예: "놓기 접근점 이동: … Out of Reach", "파지점: 물체 폭 … 최대 벌림 폭").
  - 경유점 3D 라벨과 목록에서 집기(주황)·놓기(청록) 지점을 구분하고, Waypoint로 저장하면 닫기·열기 동작이 함께 저장됩니다.
  - 실행 중 파지 직전 물체 위치를 다시 확인해 10 mm 이상 다르면 "물체 위치 변경 — 다시 계획 필요"로 정지합니다. 집지 못하면 "파지 실패"로 정지합니다.
  - `tests/pick-place.mjs` (15개 항목): 소·중·대형 각 1종이 벽 너머로 물체를 옮기는 작업을 계획하고 Rapier에서 실행을 재현합니다(운반 중 안전 위반 0, 놓은 위치 오차 0.5~3.0 mm). 실패 안내, 동작 저장 형식도 확인합니다. `run-all.mjs`에 추가.
- `tests/gripper.mjs`에 "자동 경로가 그리퍼·파지 물체 형상까지 피하는지" 점검 4개 항목 추가(그리퍼를 모르는 계획은 손가락이 벽에 −11.5 mm 침범 → 반영한 계획은 실행 궤적 전 구간 위반 0, 최소 59 mm).

### 수정
- 물리 모드로 저장된 상태를 새로고침하면, 물리엔진을 불러오기 전 고정 모드 규칙으로 검사해서 손가락이 물체를 감싼 자세에 "복원된 자세가 이미 위반 상태" 알람이 잘못 나던 문제. 저장된 모드가 물리면 처음부터 물리 규칙으로 검사합니다(물리엔진 로딩 실패 시 고정 규칙으로 다시 검사).

## [1.0.0] - 2026-10-27

첫 공개 버전. PRD의 P0·P1 요구사항(FR-1~FR-16)과 수용 기준(AC-1~AC-10)을 모두 구현하고 검증했습니다.

### 추가
- **로봇 선택:** ABB / KUKA / FANUC / NACHI 메이커 배너와 메이커별 3개 모델(총 12종). 근사 DH 모델로, 도달거리는 카탈로그 대비 ±0.61% 이내입니다. 모델 카드에 SVG 실루엣 썸네일과 "근사 모델" 배지를 표시합니다.
- **3D 뷰:** Three.js 기반으로 그림자, 바닥 그리드, 좌표축 표시, 메이커 색상 링크를 제공합니다.
- **조작:**
  - 관절 조그(한계 근접 시 색 변화)
  - 직교 조그(월드/툴 좌표계, DLS IK)
  - TCP 위치·자세 실시간 표시
- **Waypoint:** 저장, 이름 변경, 삭제, 드래그 순서 변경, PTP/LIN 재생, 속도 10~200%.
- **장애물:** 박스/구/원기둥을 수치 입력이나 3D 기즈모로 편집하고, 표시/숨김과 바닥 충돌 on/off를 지원합니다. 기즈모로 끄는 동안 충돌 미리보기를 보여 줍니다.
- **안전 감지 (기능별 ON/OFF):**
  - Self Collision, Obstacle Collision(캡슐 근사)
  - 손목·팔꿈치·어깨 특이점
  - 위반을 감지하면 마지막 안전 자세에서 정지하고, 알람 배너·알람음·로그(100건)를 남깁니다. Reset으로만 해제됩니다.
- **자동 경로 계획 (cuRobo 개념의 경량 버전):**
  - A(현재 자세/Waypoint/TCP)와 B(Waypoint/TCP)만 지정하면 중간 경유점을 자동 생성합니다.
  - 계획 순서: 다중 해 IK → RRT-Connect → Shortcut smoothing → CHOMP 스타일 최적화(장애물 거리·매끄러움·특이점 비용) → 모서리 블렌딩 → 연속 시간 파라미터화.
  - 장애물·자기 충돌은 항상 회피하고, 특이점 회피는 옵션입니다(기본 ON).
  - 도달 불가(Out of Reach)는 원인을 구분해 안내합니다.
  - 경유점은 3D 라벨과 목록으로 표시하고, Waypoint 목록에 추가할 수 있습니다.
  - 실행 시 로봇이 A에 없으면 A로 자동 접근합니다.
  - 계산은 Web Worker에서 하며, 타임아웃 5초와 취소를 지원합니다.
- **데이터:**
  - localStorage 자동 저장·복원(300 ms debounce)
  - 손상 데이터 백업 후 기본값으로 복구
  - JSON 내보내기·가져오기·초기화
- **UI:** 다크/라이트 테마, 접이식 섹션(상태 저장), 1024 px 이하 드로어, 단축키(Space/Esc/R), 한국어 + 영문 병기.
- **실행 환경:**
  - `start.bat` + `serve.py`: 캐시 금지, 앱 로드 시 사이트 캐시 비우기, JS MIME 고정, 포트 중복 감지
  - `index.html`을 file://로 직접 열면 실행 방법을 안내합니다.

### 검토 후 수정 (REVIEW.md)
- **치명 C-1:** 위반 상태에서 Reset한 뒤 다른 대상과의 새 충돌·특이점을 놓치던 문제를 고쳤습니다(대상별 복구 규칙).
- **주요 M-1~M-4:**
  - file:// 실행 안내
  - 안전 검사 최악 시간 2.08 → 0.93 ms(보수적 전진)
  - FR-16 데이터 관리
  - 경유점 정지 해소(블렌딩 + CHOMP 최적화)
- **경미 m-1~m-17:** 저장 데이터 검증, 접근성 대비, 1024 px 상태바, 플래너 안내 메시지 등 17건을 모두 조치했습니다.
- **실행 환경 E-1~E-3:** 브라우저 캐시로 인한 로봇 미표시와 Worker 오류, start.bat 인코딩 문제를 고쳤습니다.

### 알려진 제한
- 로봇 형상과 기구학은 공개 사양 기반 **근사 모델**입니다(실제 기구와 다를 수 있음).
- Three.js를 CDN에서 불러오므로 최초 실행 시 인터넷이 필요합니다(오프라인 지원은 P2).
- Chromium(Chrome/Edge)에서 검증했고, Firefox/Safari는 best-effort입니다.
