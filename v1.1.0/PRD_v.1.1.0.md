## 1. 개요

### 1.1 배경
v1.0.0은 **기구학 시뮬레이터**다. 관절 각도로 자세를 계산하고 겹침만 검사하며, 중력·질량·힘은 없다. 그래서 장애물은 항상 제자리에 고정되어 있고, 물체를 집어 옮기는 작업은 표현할 수 없다.

### 1.2 목적
브라우저용 물리엔진 **Rapier**(WebAssembly)를 통합해 다음을 할 수 있게 한다.
- 물체(박스·구·원기둥)에 중력과 충돌 반응을 적용한다.
- 간단한 그리퍼로 Pick & Place 작업을 시뮬레이션한다.
- (v1.1.1) 컨베이어와 사이클 타임 측정으로 작업 셀을 구성한다.

v1.0.0의 장점은 그대로 유지한다: 설치·빌드 없이 브라우저에서 실행, 가벼움, 안전 감지·자동 경로 계획.

### 1.3 목표 / 비목표

**목표**
- 시뮬레이션 전체를 **고정 모드**와 **물리 모드** 중 하나로 실행한다(2장).
- 물리 모드에서 물체의 낙하, 쌓임, 밀림, 굴러감, 로봇과의 접촉 반응을 실시간(60 FPS)으로 처리한다.
- 그리퍼 열기/닫기, 물체 파지·놓기를 Waypoint 재생과 자동 경로 계획에 연동한다.
- v1.0.0 저장 데이터를 자동으로 변환해 그대로 열 수 있게 한다.

**비목표**
- 로봇 자체의 동역학(관절 토크, 모터 부하, 처짐). 링크 질량·관성 데이터가 없으므로 로봇은 위치 제어 운동학 바디로 유지한다.
- 실제 CAD 메쉬 충돌, 유연체, 유체
- 물체별로 고정/물리를 따로 지정하는 기능 (2.1 규칙 0)
- 실제 로봇 컨트롤러·PLC 연동

## 2. 핵심 개념: 시뮬레이션 모드

### 2.1 규칙 0 — 모드는 시뮬레이션 전체 단위로 정한다

> 동적 물체(박스·구·원기둥)의 중력·충돌이 반영되어야 한다. **물체마다 고정/물리를 고르지 않는다.** 시뮬레이션 전체에서 실행 전에 **고정/물리 모드를 선택**하고, 모든 물체가 그 모드에 맞게 동작한다.

| 모드 | 물체 동작 | 로봇과의 관계 | 용도 |
|---|---|---|---|
| **고정 (Static)** | 모든 물체가 배치한 위치에 고정. 중력 없음 (v1.0.0과 동일) | 로봇 링크와 겹치면 장애물 충돌 감지(켜져 있을 때) → 정지·알람 | 경로 계획, 충돌 회피 검증, 레이아웃 설계 |
| **물리 (Physics)** | 모든 물체가 동적 바디: 중력, 물체끼리·바닥·로봇과 충돌 반응, 마찰 | 로봇은 운동학 바디(힘에 밀리지 않음)로 물체를 밀거나 집을 수 있음. 감지 규칙은 4.3 | Pick & Place, 물체 거동 확인, 작업 셀 |

- v1.0.0 요구사항 문서의 "장애물 패널에 고정 / 물리 선택 추가"는 **물체별 선택이 아니라 시뮬레이션 모드 선택 스위치**로 구현한다. 스위치는 장애물(물체) 패널 상단에 둔다. 모든 패널에서 현재 모드가 보이도록 상단 바와 상태바에도 모드를 표시한다.
- 물체마다 **물성(질량 또는 밀도, 마찰, 반발)** 은 지정할 수 있다. 이 값은 물리 모드에서만 쓰인다.

### 2.2 배치(Layout)와 시뮬레이션 상태의 분리

물리 모드에서는 물체가 움직이므로, 사용자가 편집한 **배치**와 실행 중의 **시뮬레이션 상태**를 구분한다.

| 구분 | 내용 | 저장 |
|---|---|---|
| 배치 (Layout) | 장애물 패널·기즈모로 편집한 각 물체의 초기 위치·자세·크기·물성 | localStorage에 영구 저장 (v1.0.0 `obstacles`) |
| 시뮬레이션 상태 | 물리 모드 실행 중 물체의 현재 위치·속도, 파지 상태 | 저장하지 않음 (새로고침하면 배치로 복원) |

- **고정 → 물리 전환:** 배치를 초기 상태로 물리 시뮬레이션을 시작한다. 공중에 있는 물체는 떨어진다.
- **물리 → 고정 전환:** 물체를 배치 위치로 되돌린다. 단, 사용자가 **"현재 상태를 배치로 저장"** 을 누르면 현재 위치를 새 배치로 확정한 뒤 전환한다.
- **시뮬레이션 리셋** 버튼: 물리 모드에서 물체를 배치로 되돌린다(로봇 자세는 유지).
- 모드 전환과 리셋은 **로봇이 움직이지 않을 때만** 가능하다. 실행 중에 누르면 안내 후 거부한다.
- 물리 모드에서 장애물 편집(추가·수정·삭제)은 **배치를 수정**한다. 편집하면 시뮬레이션을 배치로 리셋할지 묻는다.

## 3. 기능 요구사항

> 우선순위: **P0** = v1.1.0 필수, **P1** = 권장, **P2** = v1.1.1 범위(3단계)
> ID는 v1.0.0(FR-1~FR-16)에 이어 FR-17부터 매긴다.

### 3.1 1단계 — Rapier 연동, 중력·충돌 (P0)

**FR-17. 물리엔진 통합**
- Rapier(`@dimforge/rapier3d-compat`, WASM 내장 빌드)를 CDN에서 **버전 고정**으로 불러온다. 구현 시점의 최신 안정 버전을 확인해 고정하고, 버전을 PRD와 README에 기록한다.
  - **[1-A 구현] 고정 버전: `@dimforge/rapier3d-compat@0.21.0`** (2026-09-25 배포, jsDelivr `dist/rapier.mjs`, 약 4.3 MB). 같은 기기에서 결정적(로컬 결정성)이다. 물리 모드를 처음 켤 때만 불러온다(`js/physics-loader.js`).
- 물리 월드는 v1.0.0과 같은 좌표계(로봇 베이스 Z-up, 단위 mm)를 쓴다. Rapier는 SI 단위(m, kg, s)이므로 경계에서 변환한다.
- 물리 스텝은 v1.0.0의 고정 60 Hz 시뮬레이션 tick과 동기화한다(같은 tick에서 로봇 이동 → 물리 스텝 → 렌더).
- 중력: −Z 방향 9.81 m/s². 설정에서 끄거나 바꿀 수 있다(P1).
- 바닥(Z = 0)은 정적 충돌체로 항상 존재한다(마찰 0.6). Rapier는 맞닿은 두 면의 마찰·반발 계수를 평균해서 쓴다. v1.0.0의 "바닥 충돌 검사" 옵션은 로봇 안전 감지에만 적용한다.
- WASM 로딩에 실패하면 고정 모드만 쓸 수 있게 하고 원인을 안내한다(앱 전체가 멈추지 않음).

**FR-18. 동적 물체**
- 박스·구·원기둥을 물리 모드에서 동적 바디로 만든다. 형상과 크기는 v1.0.0 장애물 정의(`type`, `size`, `pos`, `rot`)를 그대로 쓴다.
- 물체별 물성(물리 모드에서만 사용):

| 속성 | 기본값 | 범위 |
|---|---|---|
| 밀도 (kg/m³) 또는 질량 (kg) | 밀도 500 (질량은 부피로 자동 계산) | 질량 0.01 ~ 1000 kg |
| 마찰 계수 | 0.6 | 0 ~ 2 |
| 반발 계수 | 0.1 | 0 ~ 1 |

- 물체끼리, 물체와 바닥, 물체와 로봇 링크 사이 충돌을 처리한다.
- 3D 뷰는 매 프레임 물리 결과(위치·회전)로 물체 메쉬를 갱신한다. 움직이는 물체는 반투명 대신 불투명하게 그려 고정 모드와 구분한다(P1).
- 화면 밖으로 떨어지거나(Z < −1 m) 일정 거리 이상 날아간 물체는 비활성화하고 목록에 "범위 이탈"로 표시한다.

**FR-19. 로봇의 물리 표현**
- 로봇 링크는 v1.0.0 충돌 모델과 같은 **캡슐**로 Rapier에 **운동학 바디**(kinematic position-based)로 등록한다.
- 매 tick 로봇 자세가 바뀌면 링크 바디 위치를 갱신하고, 로봇의 움직임이 물체에 힘(밀어냄)으로 전달되게 한다.
- 로봇은 물체에 밀리지 않는다(위치 제어).
- 빠른 이동으로 물체를 관통하지 않도록 로봇 링크와 작은 물체에 연속 충돌 검출(CCD)을 켠다.
- [1-B 구현] 로봇 링크 캡슐을 `kinematicPositionBased` 바디로 등록하고, 매 tick 안전 검사를 통과해 적용된 자세로 `setNextKinematicTranslation/Rotation`을 준다. 검증: 로봇이 J1을 돌리며 경로의 박스를 밀어냄(Node 371 mm, 브라우저 593 mm), 로봇 자세 오차 1.5e-5 mm(밀리지 않음), 같은 시나리오 2회 결과 동일.

**FR-20. 시뮬레이션 모드 선택 UI (규칙 0)**
- 장애물(물체) 패널 상단에 **"시뮬레이션 모드: 고정 / 물리"** 세그먼트 스위치를 둔다(2.1).
- 물리 모드에서는 다음 컨트롤을 보여 준다.
  - 시뮬레이션 실행/일시정지(물리 시간 정지)
  - 리셋(배치로 복원)
  - "현재 상태를 배치로 저장"
- 상단 바와 상태바에 현재 모드를 표시한다(예: `PHYS 60 Hz`). 물리 계산 시간(ms/step)도 상태바에 표시한다.
- **물리 모드로 전환할 때 안전 감지 토글은 바꾸지 않는다(결정 2).** 장애물 충돌 감지가 켜져 있으면 다음 안내를 표시한다(전환을 막지 않음). 같은 안내는 세션당 한 번만 띄운다.
  > "물리 모드에서도 장애물 충돌 감지가 켜져 있어, 로봇이 그리퍼 손가락 외의 부분으로 물체에 닿으면 정지합니다. 물체를 밀어서 움직이려면 기능 설정에서 장애물 충돌 감지를 끄세요."
- 모드 선택은 `settings.simMode`에 저장한다. 새로고침하면 같은 모드로 시작하되, 물리 모드는 배치 상태에서 다시 시작한다.

### 3.2 2단계 — 그리퍼와 Pick & Place (P0)

**FR-21. 그리퍼(엔드 이펙터)**
- 플랜지에 **평행 2지 그리퍼**를 부착할 수 있다(설정에서 켜기/끄기, 기본 끔). 형상은 근사 모델이다.
- **기본 치수는 로봇 크기별 3종이다(결정 1).** 로봇의 `sizeClass`(small / medium / large)에 따라 자동으로 고른다.

| 속성 | 소형 (small) | 중형 (medium) | 대형 (large) |
|---|---|---|---|
| 해당 모델 | IRB 1200, KR 6, LR Mate, MZ07 | IRB 2600, KR 20, M-20iD, MZ25 | IRB 6700, KR 210, R-2000iC, SRA166 |
| 길이 (플랜지 → 손가락 끝, TCP 오프셋) | 100 mm | 150 mm | 250 mm |
| 최대 벌림 폭 | 60 mm | 120 mm | 250 mm |
| 손가락 두께 / 폭 | 10 / 16 mm | 15 / 25 mm | 25 / 45 mm |
| 그리퍼 몸체 (지름 / 높이) | 50 / 40 mm | 80 / 60 mm | 140 / 100 mm |
| 개폐 시간 | 0.25 s | 0.3 s | 0.5 s |
| 최대 파지 질량 | 5 kg | 20 kg | 150 kg |

- **사용자 수정:** 그리퍼 패널에서 위 값을 바꿀 수 있다. 수정한 값은 **로봇 모델별로** 저장한다. 같은 크기 등급의 다른 모델에는 영향이 없다. "기본값으로 되돌리기"로 크기별 기본값을 복원한다.
- **입력 검증:** 길이 30~600 mm, 최대 벌림 폭 10~400 mm, 손가락 두께·폭 3~100 mm, 개폐 시간 0.05~3 s, 최대 파지 질량 0.1~500 kg. 범위를 벗어나면 입력을 제한하고 경고한다.
- **최대 파지 질량 초과:** 물체 질량이 최대 파지 질량을 넘으면 파지하지 않고 "파지 실패: 질량 초과 (x kg > y kg)"를 표시한다.

- 그리퍼를 켜면 **TCP가 손가락 끝 중심으로 이동**한다(툴 좌표계). 다음 기능이 모두 이 TCP를 기준으로 동작해야 한다.
  - TCP 표시, 직교 조그, IK, 경로 계획의 TCP 목표, 경유점 표시
- 그리퍼 형상은 다음 계산에 포함한다.
  - **자기 충돌:** 그리퍼–전완·상완 쌍 검사
  - **장애물 충돌:** 손가락 제외 규칙은 4.3 참고
  - **경로 계획**
- 조작: 그리퍼 패널(또는 직교 조그 패널)에 **열기 / 닫기** 버튼, 현재 상태(열림 / 닫힘 / 파지 중: 물체 이름), 단축키(G: 토글, P1).

**FR-22. 파지(Grasp)와 놓기(Release)**
- **파지 판정 (닫기 시):** 손가락 사이에 물체가 있으면 그 물체를 파지한다. 조건은 다음과 같다.
  - 물체의 손가락 방향 폭 ≤ 최대 벌림 폭
  - 물체가 손가락 안쪽 영역과 겹침
- **파지 방식:** 신뢰성을 위해 마찰에 의존하지 않고, 파지된 물체를 그리퍼에 **고정 연결**한다. 연결은 Rapier fixed joint 또는 운동학 추종 중 구현 시 안정적인 쪽을 쓴다. 손가락은 물체 폭에서 멈춘다.
- **놓기 (열기 시):** 연결을 해제하고 물체를 동적 바디로 되돌린다. 놓는 순간 그리퍼 속도를 물체에 전달한다.
- **파지 실패:** 닫았는데 손가락 사이에 물체가 없으면 "빈 손 닫힘"으로 표시한다(알람 아님).
- **모드별 동작:** 고정 모드에서는 파지할 수 없다. 그리퍼 개폐 동작만 하고 "물리 모드에서 파지할 수 있습니다"라고 안내한다.
- **파지 중인 물체의 취급:** 로봇의 일부로 본다(4.3). 운반 중인 물체가 다른 물체나 장애물과 부딪히면 장애물 충돌 감지 대상이 된다.
- [2-A 구현]
  - 그리퍼 좌표계 = 플랜지 좌표계(Z = 접근, X = 벌림). 충돌 모델은 캡슐: 링크 7 = 몸체, 8 = 손가락 2개, 9 = 파지한 물체(긴 축 방향 캡슐, 단면을 덮는 반경 → 보수적).
  - 자기 충돌: 전완(4)–그리퍼(7, 8) 쌍을 검사한다. 전완 캡슐 끝의 반구가 플랜지 쪽으로 튀어나와 홈 자세에서도 맞닿는 근사 오차가 있어, 이 쌍만 전완 끝을 d6만큼 잘라서 검사한다(12개 모델 홈 자세 오탐 0건). 손목 이후끼리(5~8)와 파지 물체(9)는 자기 충돌에서 제외.
  - 파지 방식은 **운동학 추종**: 파지한 물체를 kinematicPositionBased로 바꾸고 매 스텝 `플랜지 × rel` 자세를 준다. 놓으면 Dynamic으로 되돌리고 직전 물체 속도를 넘긴다(Node: 400 mm/s로 놓은 박스가 포물선으로 302 mm 지점에 착지, 이론 301 mm).
  - 손가락 개폐 속도 = 최대 벌림 폭 / 개폐 시간. 개폐 중에도 매 스텝 안전 검사를 하고, 새 위반이나 기존 위반이 깊어지면 그 폭에서 멈추고 알람("그리퍼 동작 중 충돌"). 고정 모드에서 손가락이 물체를 조이면 이 알람이 난다.
  - 집는 순간 이미 여유거리 안에 있던 받침(바닥·아래 물체)은 들어 올려 여유거리 밖으로 벗어날 때까지 파지 물체 검사에서 제외한다. 방금 놓은 물체도 그리퍼 몸체에서 떨어질 때까지 몸체 검사에서 제외한다(놓자마자 알람 방지).
  - 직선 보간·직교 조그는 TCP 자세를 보간한 뒤 플랜지 목표로 바꿔 IK를 푼다(12개 모델, TCP 직선 오차 0.01 mm). 플래너는 TCP 목표를 플랜지 목표로 바꾸고, 그리퍼·파지 물체를 충돌 모델과 궤적 최적화(CHOMP)에 포함한다.
  - 저장된 Waypoint는 관절값이라 그리퍼를 켜고 꺼도 바뀌지 않는다. 그리퍼 설정을 바꾸면 기존 계획 결과는 "다시 생성 권장"으로 표시한다.
  - 알려진 제한: 장애물 충돌 감지가 켜져 있으면 파지 물체(보수적 캡슐)가 바닥·물체의 여유거리 안으로 들어가기 전에 정지하므로, 물체를 바닥에 내려놓으려면 여유거리 위에서 놓아(떨어뜨려) 안착시킨다. 내려놓기(Place) 접촉 허용은 2-B Pick & Place에서 다룬다.

**FR-23. Waypoint 연동**
- Waypoint에 **도착 동작(Action)** 을 지정할 수 있다: 없음 / 그리퍼 열기 / 그리퍼 닫기 / 대기(초).
- 시퀀스 재생 시 Waypoint에 도착하면 동작을 실행하고, 완료(개폐 시간 경과 또는 대기 종료)된 뒤 다음 Waypoint로 진행한다.
- Waypoint 목록에 동작 아이콘을 표시하고, 드래그 순서 변경 시 동작도 함께 이동한다.
- "현재 자세 저장" 시 현재 그리퍼 상태를 동작 기본값으로 제안한다(P1).

**FR-24. 자동 경로 계획 연동 — Pick & Place 작업**
- 자동 경로 계획 패널에 **작업 유형**을 추가한다: `이동 (A → B)`(v1.0.0과 동일) / `Pick & Place`.
- **Pick & Place 입력:**
  - 집을 물체(물체 목록에서 선택)
  - 놓을 위치(TCP 좌표 또는 Waypoint)
  - 파지 방향(위에서 수직 / 현재 방향 유지)
  - 접근 높이(기본 100 mm)
- **자동 생성 순서:** 다음 구간을 각각 v1.0.0 플래너(충돌·특이점·Out of Reach 고려)로 계획하고, 결과를 하나의 작업 시퀀스로 잇는다.
  1. 현재 → 파지 접근점: 물체 위 접근 높이, 자동 경로 계획
  2. 접근점 → 파지점: 직선 하강(LIN)
  3. 그리퍼 닫기(파지)
  4. 파지점 → 접근점: 직선 상승(LIN)
  5. 접근점 → 놓기 접근점: 자동 경로 계획, **파지한 물체를 로봇 형상에 포함**
  6. 접근점 → 놓기점: 직선 하강(LIN)
  7. 그리퍼 열기(놓기)
  8. 놓기점 → 접근점: 직선 상승(LIN)
- **계획 시점의 장애물:** 물리 모드라도 계획할 때는 그 순간 물체들의 위치를 정적 장애물로 본다. 집을 물체는 1~4구간의 장애물에서 제외한다.
- **결과 표시:** v1.0.0처럼 경유점 라벨(A·1·2…·B)을 표시한다. 파지·놓기 지점은 아이콘으로 구분한다. "경유점을 Waypoint 목록에 추가" 시 그리퍼 동작이 Waypoint 도착 동작으로 함께 저장된다.
- **실패 처리:** 각 구간이 실패하면 어느 구간에서 왜 실패했는지 표시한다(예: "놓기 접근점: 도달 불가(Out of Reach)").
- **실행 중 환경 변화:** 물리 모드 실행 중 물체가 계획 때와 다른 위치로 움직이면(예: 집을 물체가 밀려남) 파지 직전에 물체 위치를 다시 확인한다. 허용 오차(기본 10 mm)를 넘으면 정지하고 "물체 위치 변경 — 다시 계획 필요"를 안내한다.

### 3.3 3단계 — 작업 셀 요소 (P2, **v1.1.1 범위**)

> 결정 3: 3단계는 v1.1.0에 포함하지 않고 **v1.1.1**에서 구현한다. v1.1.0 설계(저장 스키마의 `cell` 필드, 시뮬레이션 루프의 6번 단계)는 v1.1.1 확장을 고려해 자리만 마련한다.

**FR-25. 컨베이어**
- 박스 형태의 컨베이어를 배치할 수 있다: 길이·폭·높이, 위치·회전, 벨트 속도(mm/s, 방향 포함).
- 물리 모드에서 벨트 윗면에 놓인 물체를 벨트 방향으로 이송한다(표면 속도 방식).
- (선택) **물체 공급기:** 지정 간격(초)으로 컨베이어 시작점에 같은 물체를 생성한다. 최대 개수를 제한한다.
- (선택) **광전 센서:** 컨베이어 위 지점에 물체가 도착하면 벨트를 정지하거나 신호를 낸다. 신호는 Waypoint 동작 "센서 대기"와 연동한다.

**FR-26. 사이클 타임 측정**
- 시퀀스 재생이나 Pick & Place 실행의 시작~종료 시간을 측정해 표시한다.
- 반복 실행(N회 또는 무한) 시 회당 시간, 평균·최소·최대, 처리량(개/시간)을 보여 준다.
- 구간별(이동 / 그리퍼 동작 / 대기) 시간 분해를 보여 준다(P2).
- 결과를 CSV로 내보낼 수 있다(P2).

**FR-27. 작업 셀 프리셋 (P2)**
- 예제 셀을 불러올 수 있다: "컨베이어 → 팔레트 Pick & Place".
- v1.0.0 데이터 관리(내보내기/가져오기)에 작업 셀 요소를 포함한다.

## 4. 기존 기능과의 관계

### 4.1 유지되는 것
- 메이커/모델 선택, 관절·직교 조그, 특이점 감지, 알람/Reset, 데이터 관리, UI(테마·드로어·단축키), 실행 환경(`start.bat`/`serve.py`)
- **안전 검사의 "적용 전 검사" 원칙(PRD 6.5).** 로봇 이동은 물리엔진이 아니라 기존 안전 게이트(`motion.js` → `safety.js`)를 먼저 통과해야 한다. 물리엔진은 로봇 이동 결과를 반영해 물체 반응만 계산한다.

### 4.2 고정 모드
v1.0.0과 동일하게 동작한다. 그리퍼를 켜면 그리퍼 형상이 로봇 충돌 모델에 포함되는 점만 다르다. **v1.0.0 수용 기준(AC-1~AC-10)은 고정 모드에서 그대로 통과해야 한다.**

### 4.3 물리 모드의 안전 감지 규칙

| 상황 | 장애물 충돌 감지 ON | 장애물 충돌 감지 OFF |
|---|---|---|
| 로봇 링크(그리퍼 손가락 제외)가 물체에 닿음 | **정지·알람** (v1.0.0과 동일한 적용 전 검사) | 정지하지 않음. 로봇이 물체를 밀어냄 |
| 그리퍼 손가락이 물체에 닿음 | 허용 (파지 동작). 손가락 외 그리퍼 몸체는 링크와 같은 규칙 | 허용 |
| 파지한 물체가 다른 물체·장애물에 닿음 | 정지·알람 (파지 물체 = 로봇의 일부) | 정지하지 않음. 물리 반응 |
| 움직이는 물체가 정지한 로봇에 부딪힘 | 알람(로봇은 이미 정지 상태). 로그에 "외부 물체 충돌"로 기록 | 무시 |
| 자기 충돌 / 특이점 | v1.0.0과 동일 | v1.0.0과 동일 |

- 물리 모드로 전환해도 감지 토글은 바뀌지 않는다. 장애물 충돌 감지가 켜져 있으면 FR-20의 안내만 표시한다.
- [1-B 구현] 외부 물체 충돌: 물리 스텝 뒤 현재 로봇 자세를 다시 평가해, 이전 tick에 없던 물체가 여유거리 안으로 들어오면 정지·알람하고 로그 첫 줄에 "외부 물체 충돌"을 남긴다. 움직이는 물체가 없으면(모두 잠듦) 재평가를 생략한다.
- 물리 모드의 장애물 충돌 감지 대상은 **그 tick의 물체 위치**다. 물체가 움직이므로 매 tick 충돌 컨텍스트를 갱신한다. 성능을 위해 v1.0.0의 컴파일 결과를 재사용하고, 위치·회전만 갱신한다.
- 여유거리(margin)는 v1.0.0 설정을 그대로 쓴다. 파지 접근을 위해 손가락 영역은 여유거리 검사에서 제외한다.

### 4.4 자동 경로 계획 (물리 모드)
- 계획은 Web Worker에서 하므로, 요청 시점의 물체 위치(스냅샷)를 정적 장애물로 전달한다.
- 계획 이후 물체가 일정 거리(기본 20 mm) 이상 움직이면 v1.0.0의 "다시 생성 권장(stale)" 경고를 표시한다.
- 실행 중에는 매 tick 안전 감지가 동작하므로, 계획 이후 움직인 물체와의 충돌도 막는다.

### 6.2 파일 구조 (추가 예정)

저장소는 버전별 폴더로 나눈다(2026-10-27 결정).
```
robosim-lite/
├─ README.md, CLAUDE.md, .gitattributes, .gitignore   # 저장소 공통
├─ v1.0.0/   # v1.0.0 고정본 (태그 v1.0.0과 동일, 수정 금지) — 기본 포트 8000
└─ v1.1.0/   # v1.1.0 개발 폴더 (앱·테스트·문서) — 기본 포트 8011
```

### 6.3 시뮬레이션 루프 (v1.0.0 6.5 확장)

```
매 tick (60 Hz):
  1. q_next = 모션 소스의 다음 관절값                    (v1.0.0 동일)
  2. 안전 검사(q_next) — 물리 모드면 현재 물체 위치 기준  (적용 전 검사 원칙 유지)
     위반 → 정지·알람, 3으로 진행하지 않음
  3. q = q_next 적용, FK → 로봇 링크·그리퍼·파지 물체의 운동학 바디 목표 위치 설정
  4. 그리퍼 개폐 진행, 파지 판정/해제
  5. (물리 모드) Rapier world.step()  → 물체 위치·속도 갱신
  6. (v1.1.1) 컨베이어 표면 속도, 공급기, 센서 처리
  7. 렌더
```

| # | 기준 |

| AC-16 | 물리 모드에서 박스 위로 그리퍼를 내려 닫으면 박스가 파지되어 로봇과 함께 움직이고, 열면 그 자리에 놓인다(떨어져 안착). |
| AC-17 | Waypoint에 열기/닫기 동작을 지정하고 시퀀스를 재생하면 Pick & Place가 수행된다. |
| AC-18 | 자동 경로 계획의 Pick & Place에서 물체와 놓을 위치만 지정하면, 접근·파지·운반·놓기·후퇴 경로가 장애물을 피해 자동 생성되고 실행된다. 운반 중 물체도 충돌 회피에 포함된다. |
| AC-19 | 동적 물체 50개 환경에서 물리 모드 60 FPS를 유지하고, 같은 시나리오를 두 번 실행하면 물체 최종 위치가 같다. |
| AC-20 | v1.0.0에서 저장한 데이터·내보낸 JSON을 v1.1.0에서 열면 같은 장면이 고정 모드로 복원된다. |
