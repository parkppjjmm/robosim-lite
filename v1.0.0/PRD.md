## 1. 개요

### 1.1 배경
산업용 로봇의 동작 검토(간섭, 특이점, 경로)를 위해 보통 RobotStudio, KUKA.Sim, ROBOGUIDE 같은 메이커 전용 툴이나 Isaac Sim 같은 무거운 시뮬레이터를 사용한다. 설치와 라이선스 부담이 크고, 메이커마다 툴이 달라 여러 브랜드를 빠르게 비교하기 어렵다.

### 1.2 목적
**설치 없이 브라우저에서 바로 실행되는 가벼운 통합 로봇 시뮬레이터**를 만든다.
- 4개 메이커(ABB, KUKA, FANUC, NACHI)의 대표 로봇 모델을 한 화면에서 선택하고 조작한다.
- Self collision, 장애물 충돌, 특이점 감지를 선택적으로 켜고, 감지되면 로봇을 정지시키고 알람을 띄운다.
- 장애물을 회피하는 자동 경로 생성 기능(cuRobo와 유사한 개념의 경량 버전)을 제공한다.
- 새로고침하거나 브라우저를 다시 열어도 작업 데이터가 유지된다.

### 1.3 목표 / 비목표

**목표 (Goals)**
- 단일 정적 웹앱 (서버, 빌드 과정, 설치 없음)
- 메이커 → 모델 → 시뮬레이션의 직관적인 3단계 흐름
- 안전 기능 3종(Self collision / Obstacle collision / Singularity)과 자동 회피 경로 생성을 각각 ON/OFF
- 로컬 영구 저장 (새로고침 후에도 상태 복원)

**비목표 (Non-Goals)**
- 실제 로봇 컨트롤러 연동, 오프라인 프로그래밍(RAPID/KRL/TP/NACHI 언어) 코드 생성
- 정밀한 메이커 공식 CAD 형상 및 동역학(토크, 페이로드 관성) 재현
- GPU 기반 대규모 병렬 최적화 (cuRobo 원본 수준의 성능)
- 다중 로봇 셀, 협업(멀티유저), 클라우드 저장

## 2. 대상 사용자 및 사용 시나리오

### 2.1 페르소나
| 페르소나 | 설명 | 주요 니즈 |
|---|---|---|
| 로봇 엔지니어 | 셀 레이아웃과 로봇 선정 검토 | 모델별 작업 반경 비교, 간섭 확인 |
| 생산기술/영업 담당 | 고객 제안 단계 사전 검토 | 설치 없이 빠르게 시연 |
| 학생/교육생 | 로봇공학 학습 | 특이점, 충돌, 경로계획 개념의 시각적 이해 |

### 2.2 핵심 시나리오
1. 사용자가 **FANUC** 배너를 클릭하면 FANUC 로봇 3종이 카드로 표시된다.
2. **M-20iD/25**를 선택하면 3D 뷰에 로봇이 로드된다.
3. 장애물(박스) 2개를 배치하고 **Obstacle Collision**, **Singularity** 감지를 켠다.
4. 조그(Jog)로 로봇을 움직이다 장애물과 닿으면 로봇이 즉시 정지하고 빨간 알람 배너가 뜬다.
5. **Auto Path Planning**을 켜고 시작/목표 자세를 지정한 뒤 "경로 생성"을 누르면 장애물을 피하는 경로가 생성되고 재생된다.
6. 브라우저를 새로고침해도 선택 로봇, 장애물, 토글 설정, 저장한 자세(Waypoint)가 그대로 복원된다.

## 3. 기능 요구사항

> 우선순위: **P0** = MVP 필수, **P1** = MVP 권장, **P2** = 향후

### 3.1 메이커 / 모델 선택 (P0)

**FR-1. 메이커 선택 배너**
- 화면 상단(또는 좌측)에 4개 메이커 배너를 표시한다: **ABB / KUKA / FANUC / NACHI**
- 배너는 메이커명과 대표 색상으로 구분한다. 실제 로고는 사용하지 않는다(상표 이슈).
- 선택된 메이커는 하이라이트로 표시한다.

**FR-2. 로봇 모델 Display**
- 메이커를 선택하면 해당 메이커의 로봇 3종을 카드 형태로 표시한다.
- 카드에는 모델명, 가반하중(kg), 최대 도달거리(mm), 축 수, 간단한 썸네일(실루엣)을 표시한다.

**FR-3. 로봇 모델 선택**
- 카드를 클릭하면 3D 시뮬레이션 뷰에 해당 로봇을 로드한다.
- 로봇을 바꾸면 기존 경로 결과는 초기화하고, 장애물과 설정은 유지한다.

**기본 탑재 모델 (각 메이커 3종, 총 12종)**

| 메이커 | 모델 (소형 / 중형 / 대형) | 가반하중 | 도달거리 |
|---|---|---|---|
| ABB | IRB 1200-5/0.9 | 5 kg | 901 mm |
| ABB | IRB 2600-20/1.65 | 20 kg | 1,650 mm |
| ABB | IRB 6700-200/2.60 | 200 kg | 2,600 mm |
| KUKA | KR 6 R900 (KR AGILUS) | 6 kg | 901 mm |
| KUKA | KR 20 R1810 | 20 kg | 1,813 mm |
| KUKA | KR 210 R2700 (QUANTEC) | 210 kg | 2,696 mm |
| FANUC | LR Mate 200iD | 7 kg | 717 mm |

### 3.2 로봇 조작 (P0)

**FR-4. 관절 조그 (Joint Jog)**
- J1~J6 슬라이더와 숫자 입력으로 각 관절 각도를 조작한다.
- 관절 한계(soft limit)를 넘으면 입력을 제한하고 경고 표시한다.

**FR-5. 직교 조그 (Cartesian Jog)** — P1
- TCP 기준 X/Y/Z, Rx/Ry/Rz 이동 버튼을 제공한다. 수치 IK(Damped Least Squares)를 사용한다.
- 현재 TCP 위치와 자세를 실시간으로 표시한다.

**FR-6. Waypoint 관리**
- 현재 자세를 Waypoint로 저장, 이름 변경, 삭제, 순서 변경할 수 있다.
- Waypoint 시퀀스를 재생한다 (관절 보간 / 직선 보간).
- 재생 속도를 조절한다 (10% ~ 200%).

### 3.3 장애물 관리 (P0)

**FR-7. 장애물 생성 및 편집**
- 기본 도형을 추가한다: **박스, 구, 원기둥**
- 위치, 크기, 회전을 수치 입력하거나 3D 기즈모로 드래그해서 편집한다.
- 장애물 목록 패널에서 선택, 이름 변경, 표시/숨김, 삭제를 할 수 있다.
- 바닥(floor)은 기본 장애물로 항상 존재한다(옵션으로 끌 수 있음).

### 3.4 안전 감지 기능 — 각각 ON/OFF 토글 (P0)

세 기능은 설정 패널에서 독립적으로 토글한다. **활성화된 기능이 이상을 감지하면 로봇을 즉시 정지시키고 알람을 띄운다.**

**FR-8. Self Collision 감지**
- 로봇 링크끼리의 충돌을 검사한다 (인접 링크 쌍은 제외).
  - [근사 모델 한계] 전완–플랜지 쌍은 캡슐 근사로는 J5 한계에서 이미 겹치므로 제외한다(실제 로봇은 J5 한계가 기구적으로 막음). 대형 모델 일부는 관절 한계 때문에 J3 접힘으로 자기 충돌이 생기지 않는다.
- 링크를 **캡슐(Capsule)** 로 근사하고 캡슐-캡슐 최소거리로 판정한다.
- 안전 여유거리(margin, 기본 10 mm)를 설정할 수 있다.

**FR-9. Obstacle Collision 감지**
- 로봇 링크(캡슐)와 장애물(박스/구/원기둥) 사이의 충돌을 검사한다.
- 안전 여유거리를 설정할 수 있다 (기본 20 mm).
- 충돌한 링크와 장애물을 빨간색으로 하이라이트한다.

**FR-10. Singularity 감지**
- 다음 특이점을 감지한다.
  - **손목 특이점**: |J5| < 임계각 (기본 5°)
  - **팔꿈치 특이점**: 팔이 완전히 펴지거나 접힌 상태 (상완과 전완(J3→손목중심) 사이 각도의 임계각, J3에만 의존)
  - **어깨 특이점**: 손목 중심이 J1 축에 근접 (기본 50 mm 이내)
- 보조 지표로 Yoshikawa 조작성(manipulability) 값을 표시한다: `w = sqrt(det(J·Jᵀ))` (선속도 행을 도달거리로 나눈 무차원 값, 0 = 특이점)
- 임계값은 설정에서 조정할 수 있다.

**FR-11. 정지 및 알람 동작**
- 감지 즉시 진행 중인 모션(조그, 재생, 경로 실행)을 **정지**한다. 충돌 직전의 마지막 안전 자세로 되돌린다.
- 화면 상단에 **알람 배너**를 띄운다: 유형(SELF / OBSTACLE / SINGULARITY), 관련 링크·장애물, 시각.
- 알람음(Web Audio 비프)을 재생한다. 음소거 옵션을 제공한다.
- 사용자가 **"Reset"** 을 눌러야 알람이 해제되고 다시 조작할 수 있다. 알람 중에는 로봇 모델 변경, 데이터 가져오기/초기화도 거부한다.
- 알람 이력을 로그 패널에 남긴다 (최근 100건, 영구 저장).

### 3.5 자동 장애물 회피 모션 생성 — Auto Path Planning (P0, 토글)

cuRobo(Isaac Sim)와 개념이 유사한 **경량 브라우저 버전**이다. 기능을 켰을 때만 동작한다.

**FR-12. 경로 계획 입력**
- 사용자는 **A(시작)와 B(목표)만** 지정하고, 중간 경유점은 플래너가 자동 생성한다.
- A: 현재 자세 / Waypoint / TCP 위치·자세, B: Waypoint / TCP 위치·자세. TCP는 다중 해 IK로 관절해로 바꾸며, 현재 자세에 가까운 해를 우선한다.
- 계획은 장애물·자기 충돌을 항상 회피하고, 특이점은 계획 옵션 "특이점 회피"(기본 ON, 감지 토글과 별개)에 따라 경고 구간까지 피한다.
- 도달 불가(Out of Reach)는 "작업 영역 밖"(손목 중심이 팔 길이 밖)과 "자세(방향)·관절 한계로 도달 불가"를 구분해 안내한다.
- "경로 생성" 버튼을 누르면 계획을 실행한다.

**FR-13. 계획 알고리즘 (권장 구성)**
1. **IK**: 목표 TCP → 관절해. 여러 시드로 다중 해를 구하고 충돌 없는 해를 선택한다.
2. **전역 탐색**: 관절공간 **RRT-Connect**. 충돌 검사는 FR-8, FR-9의 캡슐 모델을 재사용한다.
3. **경로 단축**: Shortcut smoothing으로 불필요한 경유점을 제거한다.
4. **궤적 최적화** (P1): 장애물 거리 비용과 가속도 비용을 줄이는 경량 최적화 (CHOMP 스타일, 수십 iteration)
   - [구현 현황] `optimizer.js`: 경로를 12~40개 점으로 나눠 매끄러움(관절 속도²) + 장애물·자기충돌 거리 비용(CHOMP 거리 함수, 범위 ε = max(60 mm, 도달거리 10%)) + (특이점 회피 ON 시) 특이점 근접 비용을 A⁻¹ 공변 경사하강으로 줄인다(최대 40회, 250 ms). 결과는 촘촘한 구간 검사를 통과할 때만 채택한다. 이어서 모서리 블렌딩(2차 베지에)과 경로 전체 연속 시간 파라미터화로 경유점 정지를 없앴다.
5. **시간 파라미터화**: 관절 속도·가속도 한계 기반 사다리꼴 프로파일
- 연산은 **Web Worker**에서 실행해서 UI가 멈추지 않게 한다.
- 타임아웃 기본 5초. 실패하면 "경로를 찾을 수 없음" 메시지와 원인(목표 충돌, IK 실패, 시간 초과)을 표시한다.

**FR-14. 결과 표시 및 실행**
- 계획된 TCP 궤적을 3D 라인으로 미리 보여주고, 자동 생성 경유점을 A·1·2…·B 라벨과 패널 목록(TCP 좌표)으로 표시한다.
- 재생, 일시정지, "A로 이동" 컨트롤을 제공한다. 실행 시 로봇이 A에 없으면 현재 자세→A 경로를 같은 플래너로 계획해 먼저 이동한다.
- 실행 중에도 활성화된 안전 감지(FR-8~10)는 계속 동작한다.
- Singularity 감지가 켜져 있으면 플래너가 특이점 근처 구간을 비용으로 피하도록 한다 (P1).
- 생성된 경로를 Waypoint 시퀀스로 저장할 수 있다.

### 3.6 데이터 영구 저장 (P0)

**FR-15. 자동 저장 및 복원**
- 다음 상태를 변경 즉시(debounce 300 ms) 브라우저 로컬에 저장한다.
  - 선택한 메이커와 모델
  - 현재 관절 각도
  - 장애물 목록
  - 기능 토글 상태와 임계값 설정
  - Waypoint, 마지막 계획 경로
  - 알람 로그, 카메라 시점
- 새로고침하거나 재접속하면 마지막 상태를 자동으로 복원한다.
- 저장소는 **localStorage**를 사용한다 (예상 용량 < 1 MB). 데이터가 커지면 IndexedDB로 전환한다.
- 저장 데이터에 `schemaVersion`을 포함해서 이후 버전 마이그레이션에 대비한다.

**FR-16. 프로젝트 내보내기/가져오기** (P1)
- 현재 상태를 JSON 파일로 다운로드하거나 업로드해서 복원한다 (백업, 공유 용도).
- "초기화" 버튼으로 저장 데이터를 삭제한다 (확인 대화상자 포함).

### 6.5 안전 감지 루프
```
매 시뮬레이션 tick (60Hz):
  q_next = 모션 소스(조그 / 재생 / 계획경로)에서 다음 관절값
  FK(q_next) → 링크 캡슐 갱신
  if selfCollision     && selfCheck(q_next)     → stop(SELF)
  if obstacleCollision && obstacleCheck(q_next) → stop(OBSTACLE)
  if singularity       && singCheck(q_next)     → stop(SINGULARITY)
  통과하면 q = q_next 적용
```
- 충돌 판정을 적용 **전에** 수행해서 로봇이 장애물을 뚫고 들어가는 일이 없게 한다.
- 빠른 이동에서 터널링을 막기 위해 한 tick 동안 관절 변화가 크면 보간해서 세분 검사한다.
- [v1 구현] 세분 간격은 링크 위 임의 점의 이동량 상한(레버암 상한) 기준 8 mm이며, 현재 여유가 큰 구간은 "새 위반이 생길 수 없는 만큼" 건너뛴다(보수적 전진, 최악 0.6~0.9 ms/tick).
- [v1 구현] Reset 후 이미 위반 중인 자세에서 빠져나오는 이동은 허용하되, 비교는 **대상별**(링크 쌍 / 링크·장애물 / 특이점 종류)로 한다. 새 대상과의 위반은 항상 차단한다.

## 7. 수용 기준 (Acceptance Criteria)

| # | 기준 |
|---|---|
| AC-1 | 4개 메이커 배너가 표시되고, 클릭하면 해당 메이커의 3개 모델 카드가 표시된다. |
| AC-2 | 모델 카드를 클릭하면 1초 이내에 3D 뷰에 해당 로봇이 표시된다. |
| AC-3 | Self Collision을 켠 상태에서 J3를 접어 링크끼리 겹치게 하면 겹치기 전에 정지하고 SELF 알람이 뜬다. 끄면 정지하지 않는다. |
| AC-4 | Obstacle Collision을 켠 상태에서 로봇이 박스에 닿으면 정지하고 OBSTACLE 알람과 하이라이트가 표시된다. |
| AC-5 | Singularity를 켠 상태에서 J5를 0°로 이동하면 임계각 진입 시 정지하고 SINGULARITY 알람이 뜬다. |
| AC-6 | 알람 상태에서는 Reset 전까지 모션 명령이 거부된다. |
| AC-7 | Auto Path Planning을 켜고, 직선 경로가 장애물에 막힌 두 자세 사이에서 경로 생성을 실행하면 충돌 없는 경로가 생성되고 재생된다. 끄면 경로 생성 버튼이 비활성화된다. |
| AC-8 | 경로 계획 중에도 UI(카메라 회전, 패널 조작)가 멈추지 않는다. |
| AC-9 | 로봇, 장애물, 토글, Waypoint를 설정한 뒤 새로고침하면 동일한 상태가 복원된다. |
| AC-10 | 별도 설치나 빌드 없이 `start.bat`(또는 정적 호스팅)으로 실행된다. `index.html`을 직접 열면 실행 방법 안내가 표시된다. |
