# RoboSim Lite (v1.0.0)

브라우저에서 바로 실행하는 경량 **산업용 로봇 통합 시뮬레이터**입니다. ABB / KUKA / FANUC / NACHI의 대표 모델 12종을 고르고 조작할 수 있습니다. 자기 충돌·장애물 충돌·특이점 감지와 정지/알람을 제공합니다. A와 B만 지정하면 충돌을 피하는 경로와 중간 경유점을 자동으로 만들어 실행합니다(cuRobo 개념의 경량 버전).

> 모든 로봇은 **근사 모델**입니다. 공개 카탈로그 사양을 바탕으로 6축 구형 손목 표준 구조를 만들었고, 최대 도달거리는 카탈로그 값의 ±5%(실측 ±0.61%) 안에 맞췄습니다. 실제 기구와는 다를 수 있습니다.

## 주요 기능

| 영역 | 기능 |
|---|---|
| 로봇 선택 | 메이커 배너 → 모델 카드(실루엣 썸네일, 가반하중, 도달거리, 축 수) → 3D 로드 |
| 조작 | 관절 조그(J1~J6), 직교 조그(월드/툴), TCP 표시, Waypoint 저장·재생(PTP/LIN, 10 ~ 200%) |
| 장애물 | 박스·구·원기둥 추가, 수치 입력/3D 기즈모 편집, 표시/숨김, 바닥 충돌 |
| 안전 감지 (각각 ON/OFF) | 자기 충돌, 장애물 충돌, 특이점(손목·팔꿈치·어깨). 감지되면 즉시 정지·알람, **Reset**으로 해제 |
| 자동 경로 계획 | A·B만 지정 → 충돌 회피 + 특이점·도달 범위를 고려한 중간 경유점 자동 생성 → 실행 |
| 데이터 | 새로고침해도 자동 복원, JSON 내보내기/가져오기/초기화 |
| UI | 다크/라이트 테마, 접이식 섹션, 좁은 화면 드로어, 단축키 |

## 실행 방법

ES Module과 Web Worker는 `file://` 경로에서 브라우저 보안 정책으로 차단됩니다. 그래서 **로컬 정적 서버로 실행합니다.** 빌드나 설치 과정은 없습니다.

- **Windows:** `start.bat`을 더블클릭합니다. `serve.py` 서버가 뜨고 브라우저가 자동으로 열립니다(Python 필요). 검은 창은 서버이므로 사용하는 동안 열어 두세요.
- **Python:** `python serve.py` 실행 후 http://localhost:8000 접속
- **기타 정적 서버:** `npx serve .`, GitHub Pages 등에서도 동작합니다. 업데이트 후에는 브라우저 캐시를 비워야 할 수 있습니다.

Three.js는 CDN(jsdelivr, `three@0.160.0`)에서 불러오므로 처음 실행할 때 인터넷 연결이 필요합니다. `index.html`을 직접 열면 실행 방법 안내만 표시됩니다.

`serve.py`가 하는 일:
- 캐시 금지 헤더를 보냅니다.
- 앱을 열 때 사이트의 파일 캐시를 비웁니다(저장 데이터는 유지). 그래서 업데이트 후에도 예전 JS가 섞이지 않습니다.
- 포트 8000이 이미 사용 중이면 알려 줍니다.

## 사용법

### 기본 조작
1. 상단 메이커 배너에서 메이커를 고르고, 왼쪽 모델 카드를 클릭해 로봇을 불러옵니다.
2. 오른쪽 **기능 설정**에서 필요한 안전 감지(자기 충돌 / 장애물 충돌 / 특이점)를 켭니다.
3. **관절 조그**나 **직교 조그**로 로봇을 움직입니다. 위반이 감지되면 로봇이 멈추고 상단에 알람이 뜹니다. **Reset**(또는 `R`)으로 해제합니다.

### 자동 경로 계획 (A → B)
1. 기능 설정에서 **자동 경로 계획**을 켭니다. 충돌 회피를 보려면 **장애물**을 추가하고 **장애물 충돌 감지**도 켭니다.
2. 자동 경로 계획 패널에서 **A(시작)** 와 **B(목표)** 를 지정합니다.
   - A: 현재 자세 / Waypoint / TCP 좌표
   - B: Waypoint / TCP 좌표
3. **경로 생성**을 누르면 다음을 고려한 중간 경유점이 자동으로 만들어집니다. 3D 뷰에 **A·1·2…·B** 라벨로, 패널에 목록으로 표시됩니다.
   - 장애물·자기 충돌 회피(항상)
   - 특이점 회피(옵션, 기본 ON)
   - 도달 범위(Out of Reach)
4. **▶ 실행**을 누릅니다. 로봇이 A에 없으면 충돌을 피해 A로 먼저 이동한 뒤 B까지 움직입니다. **⏮ A로 이동**으로 되돌아갈 수 있습니다.
5. 필요하면 **경유점을 Waypoint 목록에 추가**로 저장합니다(이름: 경로N-A, 경로N-1 … 경로N-B).

### 단축키
- `Space`: 재생/일시정지 (계획 경로 시작 자세면 경로 실행, 아니면 Waypoint 재생)
- `Esc`: 정지 (경로 계산 취소, 드로어/알람 로그 닫기 포함)
- `R`: 알람 Reset

### 시연 팁
- 자기 충돌 시연에는 소·중형 모델(IRB 1200, IRB 2600, KR 6, KR 210, LR Mate, MZ07, MZ25)에서 J3를 끝까지 접어 보세요. 나머지 대형 모델은 관절 한계 때문에 J3 접힘으로는 링크끼리 닿지 않습니다.
- 벽 우회 예: IRB 1200에서 박스(위치 451, 0, 600 / 크기 80×300×1200)를 놓고, A = TCP(225, −390, 600, 180, 0, 0), B = TCP(225, 390, 600, 180, 0, 0)로 경로를 생성합니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| 로봇이 안 보이거나 "경로 계획 Worker 오류"가 뜸 | 브라우저에 예전 파일이 캐시된 경우입니다. start.bat 창을 닫고 다시 실행한 뒤 새로고침하세요. 그래도 같으면 Ctrl+Shift+Delete로 "캐시된 이미지 및 파일"만 삭제하세요(사이트 데이터를 지우면 저장 내용도 지워집니다). |
| start.bat 창에 "포트 8000 사용 중" 안내 | 다른 start.bat 창(검은 창)이 열려 있습니다. 모두 닫고 다시 실행하세요. |
| `index.html`을 열었더니 안내만 나옴 | file:// 직접 실행은 지원하지 않습니다. start.bat으로 실행하세요. |
| 기타 오류 | F12 → Console 탭의 빨간 메시지를 확인하세요. |

## 데이터 저장

- 작업 상태는 브라우저 localStorage의 `robosim-lite:v1` 키에 자동 저장되고, 새로고침하면 복원됩니다.
- 저장 데이터가 손상되었으면 기본값으로 시작하고, 원본은 `robosim-lite:backup` 키에 남겨 둡니다.
- 백업과 공유는 우측 패널 **데이터 관리**의 내보내기/가져오기(JSON)를 사용합니다.

## 디버그

URL 끝에 `?debug`를 붙이면(예: http://localhost:8000/?debug) 콘솔에서 `window.__robosim`(viewer, controller, getState, setState)에 접근할 수 있습니다. 브라우저 자동 테스트용입니다.

```
index.html             화면 골격 (file:// 실행 시 안내 포함)
start.bat              Windows 실행 스크립트 (serve.py 실행)
serve.py               로컬 정적 서버 (캐시 금지·사이트 캐시 비우기, JS MIME 고정, 포트 중복 감지)
css/style.css          디자인 토큰(다크/라이트), 레이아웃, 반응형
js/main.js             앱 진입점, UI 바인딩, 경로 계획 흐름(A 접근 → 실행)
js/state.js            상태 관리 + 영구 저장 (검증/마이그레이션, 내보내기/가져오기)
js/robots.json         12개 모델 파라미터 (근사 DH)
js/kinematics.js       FK / Jacobian / IK(DLS, 다중 시드) / 링크 캡슐 (DOM 비의존)
js/collision.js        캡슐-캡슐 / 캡슐-박스·구·원기둥 거리, self·장애물 충돌 (DOM 비의존)
js/singularity.js      손목/팔꿈치/어깨 특이점, 조작성 (DOM 비의존)
js/safety.js           자세 안전 평가 + 이동 구간 세분 검사(보수적 전진) (DOM 비의존)
js/motion.js           모션 컨트롤러: 모든 모션은 적용 전 안전 검사 통과
js/trajectory.js       PTP / LIN / 계획 경로(블렌딩, 연속 시간 파라미터화) 궤적 (DOM 비의존)
js/planner.js          경로 계획: A·B(IK) → RRT-Connect → Shortcut → 최적화 → 블렌딩 (DOM 비의존)
js/optimizer.js        CHOMP 스타일 궤적 최적화 (DOM 비의존)
js/planner.worker.js   planner.js를 Web Worker에서 실행 (UI 멈춤 방지)
js/viewer.js           Three.js 렌더링, 기즈모, 경로·경유점 라벨, 좌표축
js/alarm.js            정지 / 알람 배너 / 비프음 / 알람 로그
js/ui.js               테마, 섹션 접기, 드로어, 단축키
js/thumbnail.js        모델 카드 SVG 실루엣
js/plan-panel.js       자동 경로 계획 패널 (A/B 지정, 경유점 목록)
js/obstacles-panel.js  장애물 관리 패널
js/cartesian-panel.js  직교 조그 패널
js/waypoints-panel.js  Waypoint 목록 / 재생 컨트롤
```
